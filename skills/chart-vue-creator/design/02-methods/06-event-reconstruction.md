# Method 06｜异常发生后无法理解过程

## 任务与能力

依据事件记录回顾异常发生、演变和恢复，比较前后状态。适用于运维、构网事件、半导体复盘等过程分析。

- 时间轴与事件节点：定位关键阶段，标出记录来源和缺失区段。
- 趋势叠加与前后比较：关联指标变化，保持时间窗口、单位与统计口径可比。
- 分析链路记录：按任务记录步骤；保存/恢复能力以实际宿主为准。

首选时间轴、事件标记趋势或前后状态对照。事件须有时间、对象和发生内容；只有数值曲线时可展示观察到的变化点，不把推测写成事实事件或已恢复状态。

## 边界与读取

单纯走势用01；指标关系和原因诊断用04；独立对象优劣比较用05。事件先后不证明因果。
