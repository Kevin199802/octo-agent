# Method 01｜趋势洞察增强模式

## 问题与任务

周期长、点数多或震荡明显时，用户难以同时看清整体走势、原始波动和局部异常。先区分趋势比较、稳定性观察和异常定位。

## 设计能力

按任务组合：曲线平滑滑杆、原始/平滑叠加、预期形态提示、历史基线对照、异常阶段高亮、多曲线聚焦；半导体良率可过滤正常范围以突出峰谷。框选与范围调整服务局部观察，无需每次提供全部能力。

## 关键边界

- 数据平滑后原始信息保留或可恢复；不默默替代稳定性、尖峰和异常信息。
- 区分连线几何平滑与数据序列平滑；不因组件名 Smooth 推断它已实现降噪。
- 当前不要求用户提供或确认算法才能生成原型。需要数据平滑时，可选择适合任务的可解释算法和可调参数，标为本次实现并简要说明。
- 不声称复现未提供的历史 HTML 算法或内部组件能力；不把一次参数推广为通用规范。
- 业务异常阈值来自业务；未知时可由用户框选关注阶段，不称为系统判定异常。
- 预期形态、历史基线、业务目标与当前数据平滑结果分别标识；比较口径不足时不声称改善。安全区隐藏保留原值及阈值边界，可展开恢复，不删数据。

## 路由与读取

多对象多指标优劣比较走05；容器尺寸适配或截图可辅03。主目标是改变时间范围或局部观察尺度时读[07短卡](07-scale-adjustment.md)；空间尺度超出07当前四项能力时说明边界。采用平滑、基线/预期对照、安全区隐藏、多线聚焦或局部观察时读[详解](../03-references/methods/01/detail.md)；发生数据或坐标变换读[数据语义](../03-references/data-semantics.md)。案例见[案例](../03-references/methods/01/examples.md)，验收见[评价](../03-references/methods/01/evaluation.md)。

矩阵能力映射：01-01平滑、01-02原始/处理叠加、01-06安全区压缩，权威规则均在本卡详解；安全区折叠不迁入07。
