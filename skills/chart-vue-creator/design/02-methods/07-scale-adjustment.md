# Method 07｜数据尺度适配模式

时间跨度过大或局部变化被压缩时，改变观察范围并保留全局语境；不处理趋势降噪、容器缩小或安全区折叠。

| 能力 | 使用时机 |
| --- | --- |
| 07-01 时间范围 | 切换预设或自定义X轴时间窗口 |
| 07-02 框选缩放 | 在绘图区圈定感兴趣区间 |
| 07-04 局部详情 | 全局概览定位，固定跨度窗口左右移动查看详情 |
| 07-06 滚轮缩放 | 桌面端围绕指针时间锚点连续缩放 |

执行所选能力时读[详解](../03-references/methods/07/detail.md)对应节；需要示例读[案例](../03-references/methods/07/examples.md)，检查交互读[验收](../03-references/methods/07/evaluation.md)。不默认添加全部控件。07-03、07-05及通用空间缩放未在本卡覆盖，不虚构其规则。

噪声影响走势主01；安全区折叠仍01；卡片尺寸受限主03；事件回溯主06、范围操作可辅07。缺少时间字段、边界或业务聚合口径时先说明缺口，不自行改写数据或编造统计口径。
