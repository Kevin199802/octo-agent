# Method 03｜有限空间下，关键数据难以快速获取与清晰表达

来源：0916-C矩阵，沿用0916-B对概览、截图与元素调节的整合；参考半导体、CCAE、数字能源、开发者领域资料。

## 任务与能力

首页、列表、卡片、小窗口或报告中，空间限制使趋势、关键值或分布难以阅读；明确的样式与表达调节也可命中。先确定需要保留的信息和媒介，再组合下列分支，保留适用的原载体。

| 分支 | 问题线索 | 读取 |
| --- | --- | --- |
| 03-1 概览信息分层 | 需要主次信息和详情入口 | [概览分层](../03-references/methods/03/overview.md) |
| 03-2 图表轻量化 | 小图辅助元素拥挤 | [轻量化](../03-references/methods/03/lightweight.md) |
| 03-3 趋势与关键数值协同 | 走势、数值、时间与占比难兼顾 | [协同表达](../03-references/methods/03/trend-value.md) |
| 03-4 密集图形特征提炼 | 散点、箱体、热力区域重叠 | [特征提炼](../03-references/methods/03/dense-features.md) |
| 03-5 尺寸适配与表达调节 | 缩小、截图或样式调节 | [尺寸与调节](../03-references/methods/03/adaptation.md) |

只读命中分支；分支组合不计多张辅助方法。多对象列表/卡片另读[多对象浏览](../03-references/methods/03/multi-object.md)，它是跨能力应用维度，不新增方法编号。

## 边界

- 单纯异常筛选用02，趋势分析主01，多对象多指标优劣主05；03可辅助其有限空间表达。
- 信息精简不掩盖异常、缺失、单位与时间；小图不能仅整体缩放或无限缩字。半导体断点与箱数条件只在相应分支适用。
- “原貌图形”在同尺寸对照图形，保留窗口与轴布局；“恢复样式”清除参数覆盖。两者与重置窗口不同。
- 普通概览不加载快照窗口或参考HTML。只有明确旧11/半导体快照参考时，经03-5读取完整交互与资产；裸编号11按[迁移规则](../01-router/id-migration.md)处理。
- 未指定任务的“演示03”可用标明示例数据的概览起步。已指定图表时围绕该载体实现，不自动扩成五标签演示。
