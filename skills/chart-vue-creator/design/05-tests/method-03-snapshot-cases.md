# Method 03 半导体截图分支用例

以下是输入与预期，均为待执行用例，不是通过记录。基线复现与扩展分开评价。旧版归档未随包提供；当前“原貌”始终按同尺寸对照验收。

## Case 03-S01｜附件基线完整演示

输入：“请使用Method 03 半导体截图分支，参考随包的semiconductor_yield_dashboard.html生成可交互HTML，重点呈现源图右键截图、浮动窗口缩放、小尺寸图形优化和同尺寸原貌对照。没有真实数据时使用标明的示例数据。”

预期：读取完整资产；主图卡片含box 1/box 2/line/scatter/bar，默认box 1。右键菜单“截图”创建600×400非模态快照；边缘/角点可resize，标题可移动，关闭有效。420px时箱体后是水平圆头密度短条，非回归曲线或Sparkline。原貌打开恢复原始点且维持420px；多个快照独立。此用例不强制要求附件未实现的参数面板、热力图和图片下载，也不得声称已下载图片。

## Case 03-S02｜少箱与多箱语义

输入：“在小尺寸分别展示5和6个箱体，要与参考的两种箱形方法一致。”

预期：按当前可见箱体N判断；5为分箱短条，6连接median并保留异常点；不可按样本量或固定tab名称代替泛化判断。短条按各组局部最大计数归一化，不作跨组总量/概率比较。

## Case 03-S03｜两套图形边界

输入A：“检查附件默认宽499、500、501px的图形。”预期499/500优化，501完整。

输入B：“明确沿用原半导体430px规则，检查429、430、431px。”预期429/430优化，431完整。

两者均按图表宿主CSS宽度，不是viewport或导出像素；单实例只能选择一套图形阈值。回拖可逆且数据不变。

## Case 03-S04｜原貌与布局分离

输入：“420px宽的快照切换原貌，再拖动并放大到501后缩回420。”

预期：开关仅切图形，尺寸位置不跳回600×400，类别标签旋转和刻度抽稀保持有效；放大时开关可隐藏，缩回保留原貌状态；关闭开关回优化。数据/分色/数值域不变化。

## Case 03-S05｜折线参考与扩展

输入A：“复现附件line小图。”预期连线透明度0.4、峰谷横短条、其余竖短条、图例一致，不声称已做近竖直方向修正。

输入B：“补上之前说的近竖直连线处改横标记。”预期基于渲染坐标和明确当前角度容差实施，resize后重算；不平滑数据、不移动点位。

## Case 03-S06｜散点视觉与含义

输入：“复现scatter缩小后的气泡形态。”

预期按网格与类别聚合、中心均值，低透明填充+描边、大泡先绘，保留参考非线性半径映射；说明表达相对样本密集程度，不能声称面积正比或真实概率。原貌切回原始点。需定量比较时说明另选映射的取舍。

## Case 03-S07｜多窗口独立

输入：“box 1打开一个快照，再切box 2打开第二个，分别移动、缩放、切原貌并关闭一个。”

预期两个窗口保持创建时图表类型、同一数据身份，各自状态独立，主图仍能操作，无模态遮罩；关闭一个不影响其他。修改状态不能触发随机换数据。

## Case 03-S08｜布局宽高边界

输入：“核对W=399/400和图表H=349/350的布局，检查窄标签抽稀。”

预期W<400触发标题字号/多箱须布局，H<350抽稀Y刻度；按innerWidth/类别数判断标签旋转与抽稀，原貌开关不干预。默认浮窗min-width400无法拖到399，用主图窄宿主或测试夹具检查；不能改用外层窗口高度代替图表H。

## Case 03-S09｜普通首页概览边界

输入：“首页卡片很小，需要展示当前Yield值，还希望知道最近一周是上升还是下降。”

预期：无其他上下文时命中03-1/2/3，不读截图资产；若上下文明确旧Method 11/半导体截图工具则继承03-4/5任务。普通概览通过不等于截图分支通过。

## Case 03-S10｜轻量参数扩展

输入：“保留附件交互，补充点大小、透明度、边框调整。”

预期轻量入口和实际生效控件；拖动保留显式覆盖；原貌临时展示初始图形样式、关闭恢复编辑，尺寸不重置；不默认改成常驻宽侧栏，不虚报附件已实现面板。

## Case 03-S11｜真实导出扩展

输入：“把420px快照当前结果导出2倍像素PNG放PPT，排除操作控件。”

预期实际生成PNG，宽像素可840但按420CSS px保持图形模式；排除窗口栏、手柄、菜单、面板与Hover，保留图表标题/单位/图例。复制受限可下载；不能只创建快照就提示图片成功。未运行导出则记未执行。

## Case 03-S12｜热力扩展

输入：“新增热力图小尺寸色阶等高线。”

预期从连续网格与色阶生成区域轮廓，保留色块/色标；不能给单元格画边框冒充。说明这是附件外扩展，热力数值不机械套无序分类色。

## Case 03-S13｜缺样本与来源

输入：“只有箱形五数摘要，能生成真实密度吗？是否保证10秒截图？”

预期不虚构真实样本/密度，可保留摘要或标明示例。约2分钟到约10秒为用户反馈，不是本包实测或保证。未定算法不阻塞合理原型。

## Case 03-S14｜规范与视觉锚点

输入：“使用默认分类色板，保持附件布局与图形效果，不受未定义图表规范限制。”

预期通用分类色映射覆盖所有类别图、对象身份稳定；箱形/散点没有专项规范仍按本方法实现。白底主卡、轻量菜单、非模态窗口与图形形态保留。该输入明确要求附件布局时可保留其右侧图例，并说明与公共默认的差异；普通新原型仍用公共图例规则。附件bar没有累计曲线，不称为完整Pareto图。
