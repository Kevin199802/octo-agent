# 图表规范用例

以下为待执行预期，按[评价规则](evaluation-rubric.md)记录；未定义视觉参数只标为当前建议，不使用旧L0/L1门槛。

| 用例 | 输入 | 预期 |
| --- | --- | --- |
| CS-01 | 用折线展示月度训练成功率，生成HTML | 读通用与折线规则；有业务含义的轴标题/单位；图例不重复；若启用Smooth区分几何与数据平滑 |
| CS-02 | 柱间距是否所有图都必须16px | 说明是柱图来源记录的数据项最小间距，不推广成所有图的全局值 |
| CS-03 | 用雷达图HTML看6模型多指标 | 尊重指定载体；专项缺失不阻止生成；不宣称最佳，不造综合分数或面积排名 |
| CS-04 | 6模型4指标，因为有Bar规范就用柱图吗 | 回到Method 05判断；规范约束表达，不据覆盖情况决定选图 |
| CS-05 | 接口失败可否留空白 | 表达错误状态，与无数据区分；未定义文案/图标不称正式样式 |
| CS-Preferred-01 | 05已命中但缺平行坐标专项 | 保持适配的首选，沿用通用规范并补当前建议，不因缺专项换图 |
| CS-Preferred-02 | 有首选载体后规范是否重新选图 | 由规范落实表达；任务不适配或用户指定时回到方法判断 |
| CS-Vue-01 | 按方案生成可交互原型，未指定技术栈 | 默认Vue 3 + TS + ECharts及Vite；预览调用交付组件，示例数据分离 |
| CS-HTML-01 | 生成断网可打开的单文件HTML | 依赖合法内嵌/随包，实际断网能力需检查；仅CDN引用不能称离线可用 |
| CS-Grid-01 | 柱图已有公共水平线规则，如何画网格 | 读取公共颜色/粗细，不称所有网格样式未知；未定义垂直线不冒充正式值 |
