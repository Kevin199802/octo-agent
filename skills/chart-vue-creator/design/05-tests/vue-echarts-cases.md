## 跨场景生成检查

新任务：一个设备列表同时显示多台设备的当前温度及近24小时小趋势；列表单行图表空间有限，需要快速发现最近升温的对象。没有真实数据或业务告警阈值。要求直接生成 Vue 3 + TypeScript + ECharts 组件和 Vite 预览工程，不参考上述三个工程的源码。

验收：命中03的有限空间/趋势与数值能力；先呈现当前值与时间口径，再用小趋势辅助扫描；没有业务阈值不称“告警”；模拟数据明确标注；组件 props 和演示数据分离；预览页调用同一组件；实际运行类型检查、构建和目标尺寸可见性检查。若在同一会话执行，只能说明跨场景试跑，不能称为独立上下文的盲测。

执行结果（2026-10-08）：`skill-v064-device-mini/` 已生成。默认按 24 小时温度变化排序，允许按当前温度排序；12 行共用温度范围，最后一行用缺失末值验证空值表达；无阈值告警。3 项数据语义测试、类型检查和生产构建通过。浏览器检查了 280px 预览及排序变化，图形可见。判定 **PASS（同会话跨场景）**；全新上下文自动生成与业务接入仍待验证。
