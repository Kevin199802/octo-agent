# 03-1｜概览信息分层

来源：CCAE首页Mini图表、开发者状态/性能概览、数字能源电站首页。目标是先获取整体状态，按需进一步分析。

1. 按本次判断组织标题/对象、主指标、图形区、次指标。层级来自关注点，不要求每张卡填满四层；保留指标单位、时间范围及状态含义。
2. 主指标可为当前值或业务已有状态；图形补趋势，次指标提供解释。没有状态规则时显示原值/示例，不自行判正常或异常。
3. 按需求允许配置展示内容；保持同组对象结构一致，避免每卡不同导致反复找位置。配置能力需要实际生效，静态示意须说明。
4. 提供明确详情入口，带入对象和时间上下文；未接真实页面时可本地展开详情演示，不伪称后端已接入。不因有下钻就强加跨图联动。

当前值与趋势难兼顾时组合[03-3](trend-value.md)；辅助元素占位时组合[03-2](lightweight.md)。纯报告静态输出用可见文字保留关键含义，不依赖点击补足。
