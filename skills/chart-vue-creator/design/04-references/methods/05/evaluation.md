# Method 05｜验收

执行状态和质量结论见[评价规则](../../../05-tests/evaluation-rubric.md)；具体输入见[05用例](../../../05-tests/method-05-cases.md)。

| 范围 | 通过条件 |
| --- | --- |
| 方法 | 适配时采用平行坐标首选；用户指定或任务不适配的例外有理由 |
| 数据 | 保留各轴原值/单位，明确优劣方向；目标型不强行解释为向上更好 |
| 评分边界 | 无业务模型不建立综合分数、权重或排名；视觉映射不冒充业务评分 |
| 参照稳定 | Focus、Pin、筛选默认保持轴域、顺序及身份色；重算有明确操作和说明 |
| 可读性 | 以适用高亮、筛选或分组减少重叠；必要原值可读 |
| 规范 | 使用已有适用规则，未定义部分说明为设计建议；专项缺失不自动换图 |

关键语义正确但承诺交互或说明不完整可判PARTIAL。以下判FAIL：无理由覆盖首选载体；因“均衡”主动改成雷达；擅自等权评分；用面积/平直度判综合最优；把不同单位置于共同原值尺度后跨指标判优；筛选悄悄改变参照；虚构规范/API或通用数量阈值。

不要求每次对用户复述方法来源史，也不要求旧L0/L1标签。用户指定其他图表时按实际任务验收，不因遵从请求判失败。
