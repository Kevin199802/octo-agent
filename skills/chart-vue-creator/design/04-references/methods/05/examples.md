# Method 05 Examples

## 来源案例｜开发者领域

沿用原包：领域交流发现平行坐标对多对象、多指标比较具有较好的表达价值，后续纳入图表载体层，并进入共性问题矩阵 Method 05 的“可沉淀设计能力”。配套高亮、排序、方向统一、Focus/筛选。来源状态与本包运行验证分别记录。

## 6 个模型×4 个指标

TTFT（ms）、成本（$）、显存（GB）越低越好，吞吐（tokens/s）越高越好；无评分公式。采用平行坐标保留每轴原值/单位和方向，通过高亮/Pin 与单指标排序表观察相对位置。筛选保持范围和颜色，无需创建统一评价分数，无专项规范直接做原型。

## 边界

| 任务 | 处理 |
| --- | --- |
| 15 个模型仅比较 TTFT 谁最低 | 单指标排序 |
| 精确读值、逐列排序，不关心轮廓 | 表格为主，解释适配 |
| 用户指定雷达图 | 可分析并实现，不回写默认载体，不用面积排名 |
| 越接近 100 越好 | 原轴加目标，不靠反转声称向上更好 |
| 相同值/缺失值 | 相等明确显示；缺失不填 0、不伪造线段 |

## 避免偏差

不因均衡主动改成雷达、不因缺规范换图；不默默归一化等权评分；不凭面积、平直或筛选后位置变化判优劣；不无依据设对象数量硬阈值；不只靠无限颜色。

以上为方法示例，不是新增测试记录。验收入口见[测试索引](../../../05-tests/README.md)。
