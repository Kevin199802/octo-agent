# Method 05 Detail｜多对象、多指标比较

## 1. 比较任务

平行坐标是首选，每个指标独立成轴、每个对象形成跨轴折线。通过高亮、固定选择与筛选读取原值和单位。任务实际不适配或用户另有要求时可以调整；未接入专项规范不阻止实现。

可回答“对象 A 的吞吐在当前对象中相对领先、成本相对落后”，不能自动声称吞吐是其跨指标意义上的“最好项目”。综合排名使用业务已有模型；缺模型仍继续视觉比较。公共变换边界见 [数据语义](../../data-semantics.md)。

## 2. 指标方向

以下为本次补充的设计建议，后续可结合内部专项规范细化。

| 业务方向 | 默认表达 | 说明 |
| --- | --- | --- |
| 越高越好 | 高原值可位于上方 | 标注高值更优和单位 |
| 越低越好 | 可反转轴范围，使低原值在上 | 原值不取负、不变成分数，显示刻度方向 |
| 越接近目标越好 | 原始轴加目标线/点 | 两侧均可偏离目标，不声称向上更好 |
| 合理区间最好 | 原始轴加目标区间带 | 区间外优劣由业务定义 |
| 无已知好坏方向 | 按原值展示 | 不猜高/低更好 |

例：目标 100，实际 90、100、110；反转轴不能把处于目标的 100 变成单一方向的最优端点。目标未知时先展示原值、说明目标待补，不编造阈值、不阻止其他指标和原型生成。演示目标必须标记为示例，不混入真实业务结论。

业务明确需要偏离目标距离时，说明偏高/偏低是否对称、容差及原值；不为统一外观默默转换。

## 3. 轴范围与参照群体

默认建议：

1. 明确本次完整比较集合。用户已有固定展示范围时优先沿用；业务目标/容许区间可辅助标记，不自动等于轴端点。
2. 没有固定范围时，按完整集合有效值确定各轴范围并合理留白。需要显示的目标在范围外时可适当扩展范围；若用户要求固定范围，则用边缘提示说明目标在视野外，不静默裁掉。范围决定展示，不代表评分标准。
3. Hover、Pin、Focus、隐藏和筛选默认仅改变可见对象及视觉权重，保持初始化范围、轴顺序和对象色；恢复筛选返回同一参照系。
4. 真正需要放大当前对象差异时，提供“按当前对象重算范围”和“恢复比较范围”，明确参照群体已变化。静态图在图注说明范围口径。
5. 更换整份数据/业务周期需更新范围时，明确进入新比较视图；不把前后轮廓变化直接解释为业务改善。

例：10、20、100 中，20 的线性位置约为范围的 11%；只保留 10、20 并重算后会到顶端。原值不变，所以筛选不能悄悄制造“表现上升”。

某轴全部数值相同时明确显示相等，避免零跨度作分母或伪造差异。缺失/无效值不填 0，跨缺失轴的线段不能伪装成已知数据。

## 4. 视觉均衡

轮廓依赖轴范围、顺序、参照群体和方向。相对领先/落后可辅助发现值得进一步比较的对象，不能把平直程度、面积或同高度当统一业务成绩。

目标型与单调型混合时清楚标记目标，不宣称全图向上更好。业务达标判断需要业务基准；未知时使用相对位置表述。

## 5. 高亮、筛选与排序

- Hover 显示对象和各指标原值/单位；Pin 固定重点，其余弱化。
- 用所选领域规范的适用分类色板保持身份色；对象多时聚焦/分组，不只增加颜色。
- 辅助表格逐指标排序；无评价模型时不提供综合排序。
- 若开放轴重排，保持轴名、单位和方向，说明顺序仅改变轮廓阅读。
- 静态报告直接标出重点对象与必要值；无法靠交互降低重叠时分组呈现，或按真实任务调整载体。

不设“超过 N 个必换图”等通用阈值，依据实际可读性与媒介取舍。

## 6. 原型输出

给出任务、平行坐标方案、方向/范围与必要交互，直接交付原型。已定义的所选领域规范沿用；线宽、轴间距、目标标记和 Hover 等未定义处为本次设计建议。无需等待专项规范、L0/L1 或评分模型补齐。
