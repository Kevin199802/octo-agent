# Method 01｜验收

只检查任务要求或方案承诺的能力；不把平滑、缩放、多线聚焦同时作为所有趋势任务的必需项。执行状态和质量结论按[评价规则](../../../05-tests/evaluation-rubric.md)。

| 范围 | 通过条件 |
| --- | --- |
| 任务 | 区分整体方向、波动/稳定性与局部异常 |
| 平滑（使用时） | 处理口径可解释，保留原始数据；几何平滑不称降噪 |
| 局部观察（使用时） | 范围明确，可恢复；框选时有实时反馈及取消处理 |
| 多曲线（使用时） | 身份稳定，重点可辨；弱化不改变数据或参照口径 |
| 数据与规范 | 原值、单位、时间和异常可理解；适用视觉规则落实 |

主方案正确但承诺交互未完成可判PARTIAL；原始数据不可恢复、伪造异常阈值或将个案参数说成通用规范判FAIL。仅给建议时不声称浏览器行为已通过。案例见[示例](examples.md)。
