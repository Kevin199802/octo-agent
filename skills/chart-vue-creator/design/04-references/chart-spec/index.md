# 图表规范索引

先选择规范，再按图表类型读取。规范决定表达样式，不替代方法选择、数据语义与工程交付要求。

## 选择规则

| 条件 | 采用规范 |
| --- | --- |
| 用户明确指定规范 | 使用指定规范，包括半导体项目明确要求HD的情况；指定但未提供的规范不能被HD冒充，可说明采用临时方案 |
| 未指定规范，明确为半导体领域项目 | 半导体 |
| 未指定规范、领域不明 | HD |
| 明确为其他领域，但本包未收录对应规范 | 暂用HD，在交付说明中注明 |

领域依据用户需求和项目上下文，不从方法卡、示例数据或参考代码推断。不必为默认规范单独追问。用户的单次样式要求仅覆盖本次对应元素，不修改整套规范。

一次任务按所选规范读取；多领域页面按明确的模块边界选择并说明，不在单张图中无依据混用。半导体未定义部分不自动继承HD；确需参考HD时标为本次设计建议，或记录用户明确授权的继承范围。冲突先核对适用范围；未解决的条目说明临时处理，不宣称全部符合。
