# HD Spec｜图表使用

适用范围：已选择HD规范的任务。

来源：《Charts 图表使用规范.md》。以下为已记录用途和组件名称，不表示内部包或API已接入，也不是可用图表白名单。

| 分析任务 | 来源名称 |
| --- | --- |
| 类别比较 | BarChart |
| 组成/占比 | PieChart |
| 单值达成率 | PatGauge |
| 状态构成 | PatStackedBar |
| 任务进度 | Progress |

先匹配真实任务；多对象多指标比较仍按Method 05选择载体。

## 绘制与复用

已有组件提供轴、图例或单位时，通过其真实配置复用，避免重复。组件未提供必要元素时，可在目标技术栈中实现；保持数值、单位和身份映射，静态输出的必要信息直接可见。

## 饼图已知规则

来源要求设置数据和中心标题，需要时副标题；仅需扇区直接标注时显示Label。图例支持右侧居中或底部居中，未指定时沿用[公共布局](layout.md)的底部方案；右侧选项仅适用于该专项范围。

饼图不适合精确比较大量类别或细微差异；来源没有统一类别数阈值，不自行新增。上述内容不构成完整饼图规范。
