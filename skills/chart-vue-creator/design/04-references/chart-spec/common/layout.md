# HD Spec｜布局

适用范围：已选择HD规范的任务。

来源：《Charts 图表使用规范.md》及用户本轮三张标注图与逐项确认。以下为已知规则，按实际容器和媒介沿用；未定义值按当前设计实现。字体、线条和图例标记读取 [通用视觉基础](visual-basics.md)。

## 图表容器与上下文

- 图表利用分配给它的父容器；轴、标题和图例所需留白属于布局，避免裁切。
- 确保容器宽高可计算，不因未定义尺寸导致图表不可见。
- 提供业务标题、时间范围或数据口径；必要单位、图例与上下文可放在图内或明确关联的邻近位置。
- 无数据/异常在图表区域内展示状态，不留无法解释的空白。

## 多图组合

来源要求主图占最大面积、辅助图保持一致高度；适用于存在主辅关系的组合。同等比较的小多图可等面积排布，按任务明确取舍，不虚构固定面积比例。

无固定间距、断点、字号等已接入定义时可选择适合当前媒介的值，不等待补规范，也不把这些值写成全局硬规则。报告截图与容器响应见[03-5](../../methods/03/adaptation.md)；图形断点与宽高布局分别处理，普通概览不加载完整截图工具。

## 公共区域结构

| 区域 | 位置与要求 |
| --- | --- |
| 标题操作区 | 顶部左侧，包含图表标题；标题旁按钮可选 |
| 图表操作区 | 顶部右侧，可选；按任务放置筛选、刷新、放大、设置、更多等操作 |
| 说明文本 | 标题下方，可选 |
| 数据指标 | 说明下方、图形上方，可选；可含数值、单位、指标名与变化信息 |
| 坐标轴 | 按图表需要配置，布局图中标为可选 |
| 图形区域 | 图表的数据图形主体 |
| 缩放轴 | 可选；示例在横轴标签下方、底部图例上方 |
| 图例 | 根据数据解释需要设置；位置按下节选择 |

这些是可组合区域，不要求每张图都加入指标、说明、操作或缩放轴。不得把示例布局强制应用到无坐标轴等其他类型。

## 图例位置

以下为公共默认。若某图表有明确且适用的专项位置选项，按专项范围使用；不能把历史Demo位置当专项例外。当前usage中记录的饼图右侧居中属于其专项选项，不推广到箱形等其他图表。用户明确指定或媒介确需调整时说明取舍，不能声称临时布局是正式规范。

- 默认：底部，图例整体居中。
- 备选：与坐标轴单位文字处于同一水平行，靠最右侧；单位位于该行左侧。此处不是顶部标题操作区，也不是纵向排列的右侧独立图例栏。
- 按容器、信息量与任务选择公共方案或适用的专项方案，不重复创建图例。使用已有图例组件时调整该组件位置与样式。
- 位置备选均为已确认选项，切换触发条件、拥挤时换行/滚动规则未定义，可按当前设计补充。没有单位时不伪造单位文字以满足对齐；可采用默认底部方案。

## 已确认间距

| 元素关系 | 间距 | 测量口径 |
| --- | --- | --- |
| 标题文字—标题下拉图标 | 8px | 水平元素边界间距 |
| 标题行—说明文本 | 8px | 垂直区域边界间距 |
| 说明文本—单位文字区域 | 16px | 基本图表、两区直接相邻时的垂直间距 |
| 单位文字区域—绘图区 | 4px | 单位文字区域底部至绘图区顶部 |
| 筛选文字—下拉箭头 | 4px | 水平元素边界间距 |
| 筛选控件—右侧分隔线 | 12px | 筛选控件整体右边缘至右侧分隔线的距离 |
| 相邻操作图标 | 12px | 图标可见边缘之间的水平间距，不设分隔线 |
| 横轴标签区域—底部图例 | 8px | 基本图表、没有缩放轴时的垂直区域间距 |
| 图例标记—本项文字 | 4px | 水平元素边界间距 |
| 相邻图例项 | 24px | 前项文字结束至下一项标记开始 |

筛选控件整体包含文字与箭头。分隔线到其右侧第一个操作图标的间距本次未定义，不能将“筛选控件到分隔线12px”推导为分隔线两侧各12px。

文字区域按visual-basics.md规定的行高布局，不用字形墨迹高度替代行框高度。含数据指标、缩放轴，或可选区域缺省时，新增相邻关系的间距尚未规定，不把基本图的8/16/4px机械累加成空白。容器内边距、图表高度等未定义项仍按任务设计。
