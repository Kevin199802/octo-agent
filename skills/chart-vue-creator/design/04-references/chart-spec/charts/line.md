# Specific Chart Spec｜折线图

适用范围：已选择HD规范的任务；其他领域不自动继承本文件的视觉规则。

状态：PARTIAL。来源：《LineChart.md》《Charts 图表使用规范.md》。用于时间或有序类别上的变化观察；是否采用以分析任务为准。

## 必需信息

- 有核心数据源和明确X轴字段；来源以Month为例。
- 常规完整图提供具有业务含义的Y轴标题和必要单位，如Revenue (USD)、Count、Percentage (%)；避免仅写Value/Data。
- Mini或静态简化可用明确关联的标题、关键值或邻近标签保留指标与单位。这是媒介适配建议，非来源新增规则。
- 容器宽高可计算，不能因未定义尺寸导致图表不可见。

## 来源能力与边界

| 能力 | 已知范围 |
| --- | --- |
| Smooth curve | 仅确认有此配置；不推断内部已实现数据降噪，不设为所有折线的默认 |
| Step line / Area | 按任务选择，不强制全部提供 |
| Custom color / X-axis display name | 按真实接口配置，不虚构组件API |
| 水平参考/阈值线 | 有分析需要时设置；业务阈值有来源，统计参考值说明计算口径 |
| Stacked lines | 仅见于来源示例，规范仍待确认 |

趋势平滑读[Method 01详解](../../methods/01/detail.md)：区分连线几何平滑与数据处理，保留原始信息并说明参数。未提供算法时可选择可解释实现，不把候选算法写成内部事实。

## 公共规则与交互

- 根据数据识别需要配置图例；已有组件图例直接复用。身份由直接标签表达清楚时可不额外添加图例。位置见[布局](../common/layout.md)，标记/文字见[视觉基础](../common/visual-basics.md)。
- 对象身份及原始/处理曲线配色见[颜色](../common/color.md)。
- 缺失与变换见[数据语义](../../data-semantics.md)；Hover生命周期见[生成与验收](../../prototype/generation-review.md)，框选反馈、取消和恢复见[Method 01](../../methods/01/detail.md)。
- 仅半导体小尺寸/快照场景按[响应式专项](../../methods/03/semiconductor-responsive.md)改变点标记；这与数据平滑不同，不作为普通折线默认行为。

## 尚未覆盖

全局默认线宽、图内点大小/显隐、虚线用途、多线层级、垂直网格及短刻度样式；缺失段标记、大数据降采样专项策略；Tooltip视觉参数和Select/Highlight详细样式；普通折线响应断点与密度策略。已有公共网格、数据语义和方法交互规则继续适用。
