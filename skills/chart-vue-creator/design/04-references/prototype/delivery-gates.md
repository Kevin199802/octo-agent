# 原型交付门槛

先遵从用户指定的交付格式。交互工程优先使用既有承载环境；无承载工程时默认Vue 3 + TypeScript + ECharts + Vite。单文件/离线HTML仅在用户明确要求时采用，不能用HTML替代已约定的工程交付。

## 工程结构和执行

### 既有工程

按[承载工程规则](hosted-project.md)使用指定可写目录、验证门禁、预览和导出机制，不运行独立Vite结构检查，不新建或覆盖宿主配置。完整工程可由管道模板和本次组件共同组成；验证必须覆盖当前页面的实际挂载入口。门禁失败或未执行不能宣称完成。类型检查、生产构建、视觉、交互与图片导出分别按真实证据记录。

### 新建独立默认工程

至少有 `package.json`、锁文件、`index.html`、`src` 中的Vue组件与TypeScript逻辑、`README.md`、`HANDOFF.md`。预览页和交付组件使用同一实现。运行：

```bash
python3 /path/to/chart-design-advisor/scripts/check_prototype.py /path/to/output --run
```

此脚本仅适用于新建独立默认Vite工程，检查结构并执行所用包管理器的test、build。依赖未安装时按锁文件安装；环境无法运行时记录未验证。脚本执行build不自动证明包含类型检查，需结合实际命令。用户指定其他技术栈时按其工程机制验证，不套用本脚本。

## 目标尺寸和交互

在真实浏览器中分别将**图表容器**调到用户要求的宽度，记录容器实际宽度，而不是只改浏览器 viewport。对半导体四箱体截图案例，至少检查 640px 和 420px：

- 四组都能看见箱体、中位线、须和要求保留的异常值；点云与对应箱体同中心，横向跨度不会缩成一条竖线或压住相邻组。
- 420px 自动采用密度短线，短线宽度随局部计数变化；坐标轴、标题、分类名无重叠/裁切，字体仍按适用规范或说明过的尺寸方案。不能通过把 420px 窗口继续缩到 400px 来替代检查。
- 显式散点、点大小/透明度/边框、原貌、重置、右键唤窗、拖边缩放均实际触发并检查可见结果；导出后确认 PNG 文件存在、能打开、只包含图表内容。

这些是本案例的验收点，非所有图表的统一参数。只看源码、运行单元测试或展示一张宽屏截图，不能判定视觉通过。截图有缺陷就修正布局/几何，再重新检查两个尺寸。内部组件和真实业务数据未提供时，单独列为待接入。

## 最终状态

逐项写清 `PASS`、`FAIL`、`未验证` 与证据。只有适用工程结构、指定编译/构建门禁、目标尺寸和承诺交互实际通过，才称原型已验证；缺少浏览器或下载能力时交付可运行工程并指出相应未验证项。
