# 原型生成与验收要点

生成图表原型时读取；只检查当前任务使用的元素和交互，不扩大功能范围。以下来自0920试跑反馈，正式视觉数值由[所选规范](../chart-spec/index.md)维护。

## 业务与参考代码

- 用户明确的领域、对象、指标优先于方法卡案例。ICT运维不能因采用03就生成光刻机/良率数据；没有领域时可用设备A/B等中性名称与明确标注的示例指标，不暗定行业或真实告警阈值。
- 复用参考代码前区分业务数据、图形/交互逻辑、视觉样式。保留适用逻辑，替换不符任务的数据；公共字体、文字层级、图例、布局按当前适用规范重新配置。源HTML原样保存用于溯源，不代表其所有旧样式继续适用。
- Mini专项规范未接入时仍沿用适用公共规则，未定义处按本次设计处理；不能把旧Demo或临时像素值称为正式规范。用户明确忠实复现时说明与公共规则的差异。

## 公共规范落地

生成前将实际用到的元素对应到所选规范定义，生成后在目标尺寸核对：

| 元素 | 核对内容 |
| --- | --- |
| 文字 | 字体与已定义角色字号/行高；SVG/Canvas也需预留对应行框，不能仅替换font-family |
| 轴相关文字 | 分清轴标题、刻度标签、单位，读取已有定义；无定义的轴标题规则作为设计建议，不套用单位位置冒充规范 |
| 图例 | 已定义标记形态/尺寸、文字、项内及项间间距、可选位置；按公共默认或明确适用的专项例外执行（如饼图右侧居中）；不得仅因示例采用右侧竖排或缩字就照搬 |
| 布局与操作 | 对实际相邻区域核对布局文件的间距、图标和分隔线规则；不存在的区域不机械累加留白 |
| 色彩与状态 | 分类身份稳定，沿用适用色板；业务阈值和状态有来源或明确为模拟 |

具体数值从所选规范的对应文件读取；仅选择HD时读取common目录，避免在本文件维护另一份数值表。现有组件、自绘和复用Demo均需核对；真实尺寸冲突可说明取舍，不能笼统宣称全部符合。

## 尺寸语义

输出宽度、当前宿主宽度、图形优化断点分别解释。用户“做420px宽报告图”只规定输出尺寸，不等于“W≤420才优化”；明确“断点420px”才作为阈值覆盖。半导体配置及原貌行为按[响应式专项](../methods/03/semiconductor-responsive.md)，普通Mini不继承其断点。

## 悬浮提示

适用于本次有Hover的图表：
- 初始隐藏，命中有效数据目标后显示；离开目标/图表、筛选掉目标、重置或销毁时清理提示和临时hover状态。固定选择Pin与临时提示分开管理。
- Hover优先只改变既有节点样式；不要在mouseenter中重建当前目标、图例和表格行。确需重建时，在稳定容器处理事件并明确清理状态。
- 使用同一定位坐标系，按提示框实际宽高约束四边；在边缘换向，避免压住当前关键读数。指针提示通常不接收鼠标事件；含可交互内容的浮层需另定义关闭行为。
- 检查进入、移出、跨对象快速移动、边缘位置、重置/筛选。静态截图需要的关键信息放在标签或附表，不依赖Hover。

## 任务范围与证据

实现前在内部明确本次需要哪些交互及可观察结果。按用户目标判断原貌、尺寸调节、样式调节和导出是否需要，不因Method03自动加入全套编辑器。仅要求420px原貌切换时，不把未要求的拖动调节当作遗漏；用户要求可编辑截图工具时才落实对应控件。PNG导出必须真的生成文件，不能将打开快照窗口称为下载。

检查用户明确要求、方案已承诺、界面已呈现的交互：实际触发→观察变化→必要时恢复。按业务/规范/交互分别记录PASS、PARTIAL、FAIL或未验证；记录依据，源码检查与浏览器验证分开。缺运行工具时交付并说明未运行部分，不编造通过，也不要求设计师先审批检查清单。

## 通用输出前自检

按当前图表实际使用的元素检查，不要求每次在对用户的说明中展开清单。

1. 任务、业务领域、数据来源和媒介一致；示例数据有标记。
2. 原值、单位、时间、业务方向与缺失语义正确；变换按数据语义说明。
3. 无自造评分、权重、业务阈值或已确认根因。
4. 对象身份和颜色稳定；需要跨对象比较的视图在筛选后保持参照口径。有意重算轴范围时提供明确操作与说明。
5. 目标尺寸下标题、刻度、标签、状态、关键值和必要图例可读。
6. 静态视图包含判断必需的信息，不依赖悬浮提示。
7. 交互可触发、有可观察结果并能按任务恢复；无数据/失败/筛选无结果可区分。
8. 交互原型提供键盘可达的核心操作、可见焦点和必要的触屏替代；颜色不是唯一身份或状态线索。
9. 图形与文字有足够辨识度；低对比或重叠时调整，不假称通过未运行的无障碍认证。
10. 文件能打开，外部资源可用；分别写明实际运行验证和未验证部分。
