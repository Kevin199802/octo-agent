# HD规范｜布局

适用范围：已选择HD规范的任务。

按实际容器和媒介布局，未定义值作为具体方案选择。字体和线条采用[通用视觉规则](visual-basics.md)，图例采用[图例规则](legend.md)。

## 图表容器与上下文

- 图表利用分配给它的父容器；轴、标题和图例所需留白属于布局，避免裁切。
- 确保容器宽高可计算，不因未定义尺寸导致图表不可见。
- 提供业务标题、时间范围或数据口径；必要单位、图例与上下文可放在图内或明确关联的邻近位置。
- 无数据/异常在图表区域内展示状态，不留无法解释的空白。

## 卡片尺寸与内边距

| 推荐尺寸 | 栅格 | 卡片宽度 |
| --- | ---: | ---: |
| 大 | 12 | 920px |
| 中（默认） | 8 | 608px |
| 小 | 6 | 452px |
| Mini | 3 | 218px |

无尺寸要求且没有宿主宽度约束时，默认输出608px宽卡片；用户要求和承载工程实际分配宽度优先。高度按内容和任务确定，生成时提供可计算的实际高度。推荐宽度不是响应式断点，不从该表推算所有页面的栅格公式。

卡片内容内边距24px。实现按卡片整体CSS宽度（包含内边距）计算：608px卡片扣除两侧24px后，内部可用宽度560px，另有边框时再扣除；绘图区还需扣除轴、图例等占用。已有宿主提供内边距时复用，避免重复包卡或双重padding。

## Mini 信息压缩

简化顺序为Data Label、非必要Grid、次级Axis Label、关键Axis信息；其中“核心Bar不可隐藏”直接适用于柱图。通用原型按任务保留核心数据图形，不将Bar要求套成所有图表必须有柱。

实施建议：先简化可替代的数据标签、非必要网格和次级轴标签。关键轴信息可迁移至邻近标题或标签，但单位、时间范围、对象身份及判断必需的数值/异常信息不可无替代地丢失；静态图直接保留必要信息。此为信息压缩建议；不能仅因宽度为218px就隐藏唯一读数或统一缩小字号。

## 多图组合

主图占最大面积、辅助图保持一致高度；适用于存在主辅关系的组合。同等比较的小多图可等面积排布，按任务明确取舍，不虚构固定面积比例。

未定义固定间距、断点或字号时可选择适合当前媒介的值，不等待补规范，也不把这些值写成全局硬规则。报告截图与容器响应见[03-5](../../methods/03/adaptation.md)；图形断点与宽高布局分别处理，普通概览不加载完整截图工具。

## 公共区域结构

| 区域 | 位置与要求 |
| --- | --- |
| 标题操作区 | 顶部左侧，包含图表标题；标题旁按钮可选 |
| 图表操作区 | 顶部右侧，可选；按任务放置筛选、刷新、放大、设置、更多等操作 |
| 说明文本 | 标题下方，可选 |
| 数据指标 | 说明下方、图形上方，可选；可含数值、单位、指标名与变化信息 |
| 坐标轴 | 按图表需要配置，可选 |
| 图形区域 | 图表的数据图形主体 |
| 缩放轴 | 可选，可置于横轴标签下方、底部图例上方 |
| 图例 | 根据数据解释需要设置；位置按下节选择 |

这些是可组合区域，不要求每张图都加入指标、说明、操作或缩放轴。不得把示例布局强制应用到无坐标轴等其他类型。

矩形与圆形是布局形式，不构成所有图表的封闭分类。折线、柱、面积、箱形可按适用条件使用矩形结构；饼/环布局见[专项](../charts/pie.md)。仪表盘、雷达等按各自信息结构设计，不自动继承饼/环的中心值或占比标签。

## 图例位置

位置及空间不足处理统一见[图例规则](legend.md)。底部水平居中是默认；矩形右上方案位于单位所在行右端，饼图右侧方案与图形垂直居中，不混同为标题工具栏位置。

## 间距

| 元素关系 | 间距 | 测量口径 |
| --- | --- | --- |
| 标题文字—标题下拉图标 | 8px | 水平元素边界间距 |
| 标题行—说明文本 | 8px | 垂直区域边界间距 |
| 说明文本—单位文字区域 | 16px | 基本图表、两区直接相邻时的垂直间距 |
| 单位文字区域—绘图区 | 4px | 单位文字区域底部至绘图区顶部 |
| 筛选文字—下拉箭头 | 4px | 水平元素边界间距 |
| 筛选控件—右侧分隔线 | 12px | 筛选控件整体右边缘至右侧分隔线的距离 |
| 相邻操作图标 | 12px | 图标可见边缘之间的水平间距，不设分隔线 |
| 横轴标签区域—底部图例 | 8px | 基本图表、没有缩放轴时的垂直区域间距 |
| 图例标记—本项文字 | 4px | 水平元素边界间距 |
| 相邻图例项 | 24px | 前项文字结束至下一项标记开始 |
| 关键指标数字—单位 | 4px | 水平元素边界间距 |
| 指标名称—变化徽标 | 8px | 水平元素边界间距 |

筛选控件整体包含文字与箭头。分隔线到其右侧第一个操作图标的间距未定义，不能将“筛选控件到分隔线12px”推导为分隔线两侧各12px。

文字区域按visual-basics.md规定的行高布局，不用字形墨迹高度替代行框高度。关键指标区可采用标题至数值区16px、数值行至说明行4px、说明行至单位区16px作为布局建议，不作为所有图表的固定间距。含标题说明与指标、多指标组、缩放轴或可选区域缺省时，不把基本图的8/16/4px机械累加成空白。新增角色行高和图表高度等未定义项按任务设计并标明。
