# HD规范｜状态

适用范围：已选择HD规范的任务。

无数据或异常时在图表区域显示对应状态，不留无说明的空白。

接口失败、没有数据、筛选后没有匹配对象应保持不同含义，不显示伪造的 0 或把错误伪装成空结果。

Loading、具体文案/图标/颜色和重试交互尚无完整内部定义。原型需要时可自行补充适当设计，不等待规范；标记为当前方案，不宣称正式状态 Token 或内部组件能力。状态判断阈值来自业务；未知时不猜测。

静态输出将必要状态和说明直接呈现，不依赖点击或 Hover。

## Hover背景高亮

- Hover背景高亮使用#191919、5%不透明度，即`rgba(25, 25, 25, 0.05)`；不是95%不透明度，也不是整张图或数据图形统一降到5%。不再在已带alpha的颜色上重复叠加5%透明度。
- 高亮背景在数据图形下方、绘图区底色上方绘制，不能覆盖在柱形、折线、散点等数据图形上方；不能靠前景蒙层使图形身份色变暗或模糊。其他已有聚焦/隐藏状态继续按适用专项执行。
- 本条约束Hover背景的颜色与层级，不强制不同图表新增同一种背景区域。背景范围随实际命中的类别/对象及交互设计确定，不自行将局部高亮变成整张图遮罩。移出或目标失效后清理该临时背景。
- 此背景不是Tooltip卡片背景；提示卡片继续遵从[通用Tooltip规范](tooltip.md)，不把其白底改成半透明黑，也不把HD背景规则自动推广到半导体等领域。

实现时核对真实绘制顺序和最终叠色，不仅检查配置中存在该色值；Hover后数据图形应保持原有正常态填色（或专项已定义的合法聚焦样式）。
