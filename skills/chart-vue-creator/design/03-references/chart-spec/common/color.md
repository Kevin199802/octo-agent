# HD规范｜通用图表颜色

适用范围：已选择HD规范的任务。

## 默认分类色板

按以下顺序分配无序类别/对象/系列：

`#2070F3 #62B42E #715AFB #2CB8C9 #F69E39 #5CA2E9 #BF68FA #ED448A #BFB9FA #D19F00 #B8D9F9 #488E20 #D9B1FD #1C94A4 #FCCE92 #C40054 #A4ECF1 #1F55B5 #C6E9A8 #3F21B5 #FCC3E0 #127180 #FEF08A #651B8B #8FE5C2`

- 所有图表类型均可用此分类色板，例如柱、线、散点、平行坐标、箱形、饼图等，不限于柱状图。
- 同一对象在不同图、图例、表格标识中保持一致颜色。首次建立身份映射后，排序、筛选、Focus、分页或切换视图不重新按当前顺序配色；新增身份分配下一可用色。
- 同一对象原始/平滑曲线沿用身份色，用线型、透明度或标签区分状态。
- 默认不要为了美化重做色板。用户要求改色时，可按明确任务调整并说明是本次覆盖，不修改默认色板知识。
- 超过 25 个身份时优先分组、筛选、聚焦或补充其他编码；不在同一可见集合中无提示循环颜色导致身份混淆，不声称自行扩展色是正式默认色。

## 分类色与数值/状态编码

“所有图表可用”是图表类型范围；具体颜色含义仍由数据决定。类别/对象用分类色；连续量热力或顺序数据按任务设计顺序/发散色阶，未知部分标为本次建议，不把类别色顺序伪装成连续大小顺序。

功能色：

`#E02128 #F4840C #FCC800 #09AA71 #2070F3 #AEAEAE`

功能色的完整状态映射未定义。不要仅凭颜色猜测正常/告警/严重等级对应关系。已有业务定义时沿用；临时状态演示使用文字/图标配合，并标注当前设计。

## 颜色编辑

提供颜色编辑面板时，基础色按顺序展示；允许替换数据项颜色，已用色失效，替换后释放旧色；基础色与功能色不可交互。不要求每个图表提供该面板，也不阻止同一对象跨图复用身份色。

Token名称与接口映射未提供，不能虚构Token API。

## 公共元素中性色

标题/操作、说明/单位/图例、X/Y刻度、背景水平线的中性色与字体参数统一维护在 [通用视觉基础](visual-basics.md)。这些颜色用于公共元素，不改变上述分类色板及身份映射。
