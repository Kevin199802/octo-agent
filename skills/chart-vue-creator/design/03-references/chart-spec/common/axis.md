# HD Spec｜坐标轴

适用范围：已选择HD规范的任务。

## 规则

- Tick 与网格线保持一致；
- 控制刻度数量，避免标签拥挤；
- 长文本使用截断、换行或缩写；
- 单位需要明确展示。
- 柱状图以长度比较数值时默认显示零基线；如任务确需截断数值轴，清楚标出截断并避免将长度差误读为完整比例。负值与正值同时出现时零线需可辨。
- 对数轴只用于适配正值或另有明确的有符号变换定义；零值和负值不能被静默丢弃。非线性尺度在轴和说明中明确标识。

该文件用于补充基础坐标规则，不替代业务专项规范。

## 刻度标记与轴线

来源：2026-10-19通用规则补充文档及用户澄清。2×2px矩形刻度标记颜色为#F3F3F3；垂直图表中紧贴底部水平基线。小标记不替代整条轴线、网格或业务参考线，也不要求无坐标轴的图表增加刻度。

水平条形图原文的“刻度线”经用户澄清，指最左侧的垂直轴线。其位置记录为轴文本右侧10px；具体测量边界未定义，实现时说明本次采用的边界。原文“平行水平网格线”与该方向矛盾，不沿用。2×2px参数不用于整条垂直线；该线的线宽/颜色未另获确认，不套底部水平基线参数冒充已有规范。

背景水平线的已定义参数继续见[视觉基础](visual-basics.md)。
