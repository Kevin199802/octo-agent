# HD规范｜图表使用

适用范围：已选择HD规范的任务。

以下列出图表用途和组件称谓，不代表可调用的内部包或API，也不限制其他适用图表的选择。

| 分析任务 | 图表称谓 |
| --- | --- |
| 类别比较 | BarChart |
| 组成/占比 | PieChart |
| 单值达成率 | PatGauge |
| 状态构成 | PatStackedBar |
| 任务进度 | Progress |

先匹配真实任务；多对象多指标比较仍按Method 05选择载体。

## 绘制与复用

已有组件提供轴、图例或单位时，通过其真实配置复用，避免重复。组件未提供必要元素时，可在目标技术栈中实现；保持数值、单位和身份映射，静态输出的必要信息直接可见。

## 饼图

读取[饼与环专项](../charts/pie.md)：布局、标签、可选中心信息及数据口径。图例读取[公共图例](legend.md)。中心信息按任务选用，不强制每个饼图都有，也不将其推广到其他圆形外观图表。
