# 通用组件｜桌面端 Tooltip

来源：用户提供《chart-tooltip-general-spec.md》，2026-10-20接入；原文未标标准版本。适用于跨图表类型的桌面鼠标Hover提示。按分析任务选择触发，按数据结构选择内容布局。

本组件由用户明确指定为通用规范，适用于HD和半导体等采用本包规则的图表，不是跨领域自动继承HD。用户明确指定其他Tooltip规范时遵从；既有业务组件/领域接口契约继续生效，真实冲突说明差异及本次处理。移动触屏不在本文定义范围；原型另有触屏或键盘要求时仍需按任务提供替代方式，不声称本文已定义。

## 基础视觉与文字

| 属性 | 规范值 |
| --- | --- |
| 四周内边距 | 16px |
| 圆角 | 8px |
| 边框 / 背景 | 无描边 / #FFFFFF |
| 阴影 | 0px 8px 24px rgba(0,0,0,0.08) |
| 多列分隔线 | 1px，#F3F3F3 |
| 卡片内系列圆点 | 8×8px圆形，继承对应系列身份色 |

优先Harmony OS Sans，使用实际安装或合法资源声明的字体名称；未提供字体文件时不声称已加载，不可用时回退可用中文无衬线字体并记录。文字按以下角色应用，不套用外层图表标题或图例角色。

| 文字角色 | 字号 / 行高 | 颜色 |
| --- | --- | --- |
| 标题 / 维度（如时间、日期、对象或指标标题） | 12px / 20px | #777777 |
| 数据名称 / 子指标 | 12px / 20px | #191919 |
| 数值、百分比及带单位的数据 | 12px / 20px | #191919 |

字重未在附件明确，实现选择记录为本次建议。同一名称按其在布局中的角色取色，不仅按字面“对象名称”判断。卡内8px圆点不改变半导体图外10px图例等已有组件规则。

标题—数据内容8px；同组指标行间8px；不同内容组间12px；多列分隔线左右各留16px。按实际相邻关系使用，不将同组/异组间距叠加到同一空隙。名称左对齐、数值右对齐，二者弹性分隔；长名称或数值优先换行保留信息。圆点与名称间距、列宽和最小宽未定义，不搬用外层图例间距冒充卡片规则。

## 四种内容布局

| 形态 | 结构 | 选择依据 |
| --- | --- | --- |
| 基础单项 | 时间/维度标题；下一行圆点与名称在左、数值在右 | 单个数据项查看，如单线、单柱 |
| 单组指标拆解 | 首行圆点与对象名称；下方逐行子指标名与值 | 一个对象有多个字段，如区间/瀑布；字段有来源，不从图形反推 |
| 多组对比拆解 | 对象按列；每列名称及指标列表；列间垂直分隔线；各列同一指标顺序 | 有明确对象—指标对应关系的双组/多组对比 |
| 多系列列表 | 时间/维度标题；逐行圆点、系列名、值 | 同一坐标位置多系列对比，沿用既有系列/图例顺序 |

同图可按场景使用不同形态。多系列展示全部对应系列，内容过长采用内部滚动，不任意截成Top N。附件未明确已隐藏系列的范围；本次实施约定为当前图表可见且在该坐标有定义对应关系的系列，图例隐藏项不自行重新出现；用户另有要求时说明范围。可见系列的缺失值保留对应行，按下文显示；不把其他时间的最近样本伪装为同一时刻。不同时间采样对齐须有明确口径，遵从[数据语义](../../data-semantics.md)。

## 触发与数据内容

- 数据项触发：命中具体点、柱、扇区等，显示该项信息。
- 坐标轴触发：需要比较同一时间/坐标位置多个系列时优先采用，展示全部对应系列，不仅显示最近曲线。非时间坐标按实际维度关联，不强制改成时间轴。
- 时间格式与图表X轴粒度和格式一致；数值精度沿用图表口径；必要单位直接展示，同指标一致。不新增评分、阈值或隐藏关键指标。
- 缺失统一显示`---`，真实零仍为0；无效/未采集等原因有依据时保留必要解释，不将其变成有效数值。系列颜色继承身份映射，不重分色。
- 默认沿用图例/系列顺序；明确的排名分析可另排序并说明依据。

## 定位与尺寸

随光标移动，卡片边缘与光标保持4px间隔，默认右下；右侧不足转左侧，下方不足转上方。翻转后按实际宽高再次限制在浏览器视口内。采用同一定位坐标系；嵌套滚动、宿主裁切或弹窗需检查实际可见结果，不把图表边界当成唯一视口边界。

普通卡片最大宽320px，多列对比最大宽480px；按内容自适应，不强制撑满。视口更窄时收缩卡片可用宽度，内容换行或滚动，不固定宽度造成卡片溢出；不能仅以裁切内容实现“不出界”。

**待评审建议，非定稿参数**：距视口边缘至少8px；最大高度320px，可用高度不足时先适配视口；超长内容内部滚动。采用这些建议参数时在HANDOFF标记本次建议。普通宽度上限320px是已定义规则，不与建议高度320px混淆。

## 显示、保持与隐藏

初始隐藏，命中有效数据目标后显示；跨点及时更新，连续移动稳定，不闪烁或重复显隐。Hover优先改变既有节点样式；不要在mouseenter中重建当前目标导致事件循环。

普通只读卡片不额外放按钮，离开有效图表交互区域后隐藏。需要内部滚动的长卡片是例外：从数据目标移入卡片时保持显示，进入后可滚动。实施建议：光标进入卡片后保持稳定位置，避免追随指针妨碍滚动；离开图表有效区域与卡片组成的交互区域后隐藏。跨4px间隙需保持可到达，不在离开目标时立即销毁。具体延迟/过渡实现未在来源定数值，属于本次实现选择。

因此，只读且无需滚动的提示可不接收指针事件；可滚动卡片必须能接收指针/滚轮，不能统一设置为不接收事件。筛选掉目标、重置、切换数据或销毁时清理失效提示与临时状态。固定选择Pin是独立功能，不因这份Hover规范自动增加。

实施提醒：区分Tooltip自身及后代节点的内部滚动与页面/外部宿主滚动。内部滚动保持当前卡片和目标，不触发全局隐藏清理；外层滚动改变定位关系时按实际坐标重定位或关闭，滚动传递到外层时按事件来源及实际位移处理。销毁时解除对应监听；不强制采用全局capture监听或固定延迟。

## 实现与核对

优先配置真实业务组件；需要定制时结合实际图表引擎与DOM卡片实现，核对真实接口，不虚构已有内部API。半导体宿主协议见[领域接入](../semiconductor/integration.md)，保留其宿主/Bridge契约；只增加通用内容、视觉与交互要求。多列、换行和滚动需要核对承载方式，不能声称只配置基础原生Tooltip就已实现全部规范。

实际检查四种布局、同轴多系列、长名称、缺失/零值、上下左右边缘、窄视口、长卡片移入滚动、移出/筛选/重置清理及多实例隔离。静态图必需信息放标签/附表，不依赖Hover；视觉、交互和业务组件适配分别记录证据与未验证项。
