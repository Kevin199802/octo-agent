# HD Spec｜矩形树图

适用范围：已选择HD规范的矩形树图（矩形树状图、Treemap）。来源：用户提供的《19 矩形树状图.svg》、配图及[Pixso组件](https://pixso.cn/app/design/LKicparJUq-bRtk2GiQvtQ?item-id=4953:1)，2026-10-20读取组件属性并经用户确认下述取舍。仅补充树图专项，外层沿用[HD入口](../hd.md)。

## 图形与标签

| 元素 | 定义 |
| --- | --- |
| 矩形块 | 4px圆角，无描边；相邻块分隔间距1px，白底下呈白色间隙，不叠加额外描边造成双倍间隔 |
| 块内标签 | HarmonyOS Sans SC，Regular，14px / 22px，#FFFFFF；整体在块内水平、垂直居中 |
| 标签内容 | 按任务显示名称、数值或占比，可组合，不强制同时显示三者 |
| 标签溢出 | 空间不足时省略，不越过块边界覆盖其他对象；桌面Hover补充完整信息 |

字体使用真实可用名称；本包不含字体文件，不声称已加载HarmonyOS Sans SC，不可用时按[视觉基础](../common/visual-basics.md)回退。省略基于实际可用空间，不照搬示例的固定字符数；极小块连省略号也放不下时可不绘制文字，通过Tooltip或任务所需的列表/详情保留访问方式。

图表标题沿用HD通用20px / 28px、Medium，说明、操作与图例继续采用各自公共角色。来源组件标题为16px / 24px，用户已确认以现行HD通用标题为准，不新增树图标题例外。

872×460仅为来源实例尺寸。按宿主和目标输出尺寸重新布局，不固定每个矩形的宽高、坐标或数量；不把图中标题区到图形区的总距离定为新的通用留白。

## 面积、分组与颜色

- 用面积表达同口径、可比较的非负量，分组关系来自数据；父子汇总避免重复计数。零、缺失、无效和负值不伪造成有意义的正面积，按任务说明处理；不通过任意加最小值改变占比。
- 同组使用同一色系，不同组按[HD颜色规则](../common/color.md)建立稳定身份映射。色系内部允许深浅变化，不要求所有子项都取分类色板中的不同颜色。
- 单张图的深浅只选择一种含义：数值大小或层级。明确具体字段/层级、深浅方向及比较范围；不同时把深浅当作两者，也不默认“越深越大”或“越深层级越深”。任务未决定时提出一种选择并说明依据。
- 来源示例有蓝、绿、紫、青色系，但并未提供完整、单调的数值色阶或层级映射。示例中的深浅色不构成新增通用色板，不按矩形位置、名称顺序或样例大小反推映射。
- 色彩含义与面积、标签共同可解释；浅色填充配白字时检查实际辨识度。如需调整填充或文字颜色，说明本次取舍，不将调整值冒充来源规范。
- 占比须明确分母是全图、父级还是可见子集；过滤、聚焦或下钻后，面积、标签及Tooltip保持约定口径。来源未定义统一分母，不自行固定为全图或父级。

## 结构与交互

外层标题、说明、操作区、状态和按需出现的图例复用HD公共规则。矩形树图不强制添加坐标轴，也不因示例没有图例就禁止图例；是否展示由分组识别及任务需要决定。

桌面Tooltip按[通用组件](../components/tooltip.md)使用数据项触发，展示命中对象的完整名称、原值、单位及需要的占比/所属组或路径。字段按数据实际提供；不把分组路径写成已存在的导航功能。原值与占比不能从屏幕面积反推。

“常规交互/结构”表示复用已有适用规则，不自动增加点击下钻、面包屑、返回上级、框选或多选。任务需要时再定义入口、作用范围和恢复方式；Hover高亮与选中态的具体视觉参数未由本来源定义，按本次方案说明。

静态报告所需信息不得只藏在Tooltip中。若小块标签被省略，按阅读目标提供可见的名称/数值说明或附表；不因屏幕能Hover就声称导出图片信息完整。

## 实现边界

优先使用业务真实组件及其公开能力；没有可用接口时按工程交付规则实现。圆角、1px间隙、标签省略和居中需作用于实际绘制的矩形及文字，不能仅给Canvas/SVG外壳设置CSS后声称实现。核对当前图表库/封装版本，不能虚构配置项；无法达到的部分或需额外渲染配合时，按[能力边界](../../prototype/echarts-capabilities.md)告知并写入交接说明。

来源未定义标签内边距、多字段排列、最小块尺寸、布局算法/排序、下钻与缩放参数、完整色阶及状态样式；需要时作为当前方案选择，不扩大为HD正式规则。
