# HD规范｜折线图

适用于采用HD规范的折线图，其他领域不自动继承。用于时间或有序类别上的变化观察，是否采用以分析任务为准。

## 必需信息

- 有明确的数据源和X轴字段。
- 常规完整图提供具有业务含义的Y轴标题和必要单位，如Revenue (USD)、Count、Percentage (%)；避免仅写Value/Data。
- Mini或静态简化可用明确关联的标题、关键值或邻近标签保留指标与单位。此方式用于媒介适配，不要求所有图表采用。
- 容器宽高可计算，不能因未定义尺寸导致图表不可见。

## 默认线条与点标记

| 元素 | 规则 |
| --- | --- |
| 普通折线 | 线宽2px；线头平直（butt），拐角采用直线斜接（miter），不使用圆头或圆角连接；几何平滑另按任务启用 |
| 图内数据点 | 默认隐藏；Hover命中有效数据点时显示对应点，移出后隐藏；坐标轴触发时仅显示当前坐标上实际对应的可见系列点，不显示全量点，不跨缺失处补点；仅有一个有效样本的序列、或按缺失断开的单点分段，须常显标记或提供等价可见表达，使其在未Hover及静态导出中仍可识别 |
| 多系列基础层级 | 按稳定身份色在分类色板中的顺序由下向上叠放：第一色对应系列在下，后续颜色对应系列依次在上；筛选、图例隐藏/恢复不重新分配颜色或颠倒已有相对层级 |

用户定制颜色或多系列共用身份色时，沿用首次建立的系列身份顺序补足层级，不按颜色亮度或每次数据排序重排。图例与Tooltip顺序不因绘制层级改变；此处的叠放指遮挡顺序，不是数值堆叠，也不表示业务优先级。任务需要临时Hover强调时可临时置顶，移出后恢复基础层级。

普通折线不透明度推荐采用100%，作为未指定时的实现预设；它不是已确认的HD透明度参数。点的大小及形状、原始/处理线的具体区分样式按任务选择并说明；除上述孤立有效点的可见表达外，默认不额外增加固定点、选中点或全量常显点。虚线可用于区分参考线或处理状态，但须由图例/标签解释，不赋予未知业务含义。原始/处理曲线继续保持同一对象身份色。

## X轴顺序与数据对齐

- 时间轴按真实时间位置表达，不等时间间隔不默默画成等距类别；有序类别沿用业务顺序，不按Y值排序制造走势。
- 时间序列按时间戳排序，同一时间戳有多条记录时按业务键拆分或采用有依据的聚合，不任意覆盖、平均或连接成无解释的折返。
- 明确时间戳、时区、采样及重复记录处理；缺失不补零、不跨缺失段连线。具体处理引用[数据语义](../../data-semantics.md#时间采样与平滑)，不在本章另设聚合算法。

## 配置与使用边界

| 能力 | 已知范围 |
| --- | --- |
| Smooth curve | 按任务启用；几何平滑不等同于数据降噪，不设为所有折线的默认 |
| Step line / Area | 按任务选择，不强制全部提供 |
| Custom color / X-axis display name | 按真实接口配置，不虚构组件API |
| 水平参考/阈值线 | 有分析需要时设置；业务阈值有来源，统计参考值说明计算口径 |
| Stacked lines / Area | 仅对可加总、同单位和同口径系列使用；按[堆叠语义](../../data-semantics.md#堆叠)区分分项、累积和占比，不能把累计曲线当分项原始走势 |

趋势平滑读[Method 01详解](../../methods/01/detail.md)：区分连线几何平滑与数据处理，保留原始信息并说明参数。未提供算法时可选择可解释实现，不把候选算法写成内部事实。

## 公共规则与交互

- 根据数据识别需要配置图例；已有组件图例直接复用。身份由直接标签表达清楚时可不额外添加图例。位置见[布局](../common/layout.md)，标记/文字见[视觉基础](../common/visual-basics.md)。
- 对象身份及原始/处理曲线配色见[颜色](../common/color.md)。
- 缺失与变换见[数据语义](../../data-semantics.md)；桌面Hover的视觉、布局及生命周期见[通用Tooltip组件](../common/tooltip.md)，框选反馈、取消和恢复见[Method 01](../../methods/01/detail.md)。
- 仅半导体小尺寸/快照场景按[响应式专项](../../methods/03/semiconductor-responsive.md)改变点标记；这与数据平滑不同，不作为普通折线默认行为。
