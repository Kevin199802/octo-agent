# HD规范｜柱状图

适用于采用HD规范的柱状图，其他领域不自动继承。

## 方向与数据

支持垂直柱图、水平条形图和堆叠图，默认垂直布局。明确类别、数值、指标名称和单位。

| 方向 | 类别轴 | 数值轴 |
| --- | --- | --- |
| 垂直向上 | X轴 | Y轴 |
| 水平向右 | Y轴 | X轴 |

轴标题和单位随方向按实际含义配置，不固定使用垂直布局的轴名称。

## 视觉样式

| 项目 | 规则 |
| --- | --- |
| 柱宽 | 2–16px；编辑器默认8px，编辑时取偶数 |
| 数据项间距 | 相邻类别组最外侧柱形边缘之间的净间距，最小16px；不是类别中心间距 |
| 同一数据项内部柱间距 | 同一类别组内相邻柱形边缘之间4px；堆叠分段不套用此间距 |
| 垂直普通柱圆角 | 顶部两角4px，底部两角无圆角 |
| 水平普通条形圆角 | 右端两角4px，左端两角无圆角 |
| 垂直堆叠圆角 | 仅最上方可见分段的顶部两角4px，其余角均无圆角；中间分段四角无圆角 |
| 水平堆叠圆角 | 仅最右侧可见分段的右端两角4px，其余角均无圆角；中间分段四角无圆角 |

圆角按每个类别、每个独立堆叠组分别判断。只有一个有效可见分段时，按普通柱或条形处理。

柱宽低于8px或柱高很小时，端部圆角参数仍保持4px，不随柱宽、柱高等比缩小，也不改成0。实际路径受图形边界和渲染器几何约束，不扩大柱形、改变数值长度或用最小柱高伪造数据来容纳圆角；需要额外渲染实现时按能力边界说明。

隐藏或恢复系列、筛选、更新数据或调整堆叠顺序后，重新判断最外侧可见分段。缺失或零值且未绘制的分段不占用最外侧位置。分段连接处和基线端保持直角，不能将最后一个系列固定为所有类别的圆角分段。

圆角应用于实际柱形分段，不能用外层容器圆角替代。以上柱宽和间距用于本章的柱图场景，不推广为其他图表的通用参数。

## 空间自适应

沿类别排列方向，按扣除坐标轴、图例等占用后的实际绘图区长度判断容量；水平条形图对应可用高度。类别组宽度包含本组所有并列柱或独立堆叠柱及其内部4px间距。

1. 自动布局优先保持可容纳的最大柱宽，上限16px；空间收紧时先减少类别组间净间距，直到16px。编辑器初始柱宽仍为8px；已有用户指定柱宽时先以该值为目标，不自行放大到16px。
2. 类别组间距已为16px仍放不下时，再减少柱宽，按偶数档位调整，最小2px；组内4px间距保持不变。不能用小于16px的组间距或小于2px的柱宽继续挤压。
3. 柱宽2px、组间距16px仍不足时，优先采用范围缩放或沿类别方向滚动；按任务选择，不要求同时提供两者。
4. 缩放或滚动仍不适合任务、媒介时，最后减少同时展示的类别数量，明确当前范围和总量，并提供翻页、切换范围或静态续图/附表；不静默删除类别，不默认以Top N替代完整数据。

可用空间恢复时按同一容量规则重新计算：先在不小于16px组间距的前提下恢复目标柱宽，再分配额外间距。只有一个类别时不计算组间距。标签压缩按[Mini布局规则](../common/layout.md#mini-信息压缩)另行处理，标签抽样不等于删除数据。

## 交互与配置

按任务需要启用配置，不要求全部展示。

| 配置 | 规则 |
| --- | --- |
| 类别轴 | 可显示或隐藏；标签可完整显示、抽样、倾斜、省略或双行展示 |
| 数值轴 | 可显示或隐藏；分割线默认4；最小值、最大值可自动计算或编辑；单位按需配置 |
| X轴单位 | 可单独配置，不自动等同于数值单位 |
| 网格 | 默认显示，可关闭；水平线颜色和粗细采用[通用视觉规则](../common/visual-basics.md) |
| 缩放轴 | 默认隐藏，可开启；支持Mini和默认模式 |
| 阈值与辅助数据 | 可显示、隐藏或编辑；阈值必须有业务依据 |
| 右侧第二Y轴 | 仅垂直布局、确有不同单位或尺度的指标需同图展示时按任务考虑；类别数或系列数多于1不是充分条件。明确系列与轴的绑定、单位和范围，独立轴的柱高不直接用于跨指标绝对量比较 |
| Hover背景 | 采用[HD状态规则](../common/state.md#hover背景高亮)，背景位于数据图形下方 |
| 图例 | 采用[图例规则](../common/legend.md)，隐藏、恢复及分页不改变对象身份色 |
| 悬浮提示 | 采用[通用Tooltip规范](../common/tooltip.md) |

## 数据与使用边界

- 长度编码默认使用零基线。编辑最小值不能造成无提示截断；负值、截断及非线性尺度遵从[坐标轴规则](../common/axis.md)。
- 负值向下或向左、正负混合、反向轴的端部圆角未定义，按具体方案说明，不直接套用向上或向右规则。
- 分段圆角调整不改变原值、堆叠口径、数据可见性或身份色。
- 普通与百分比堆叠遵从[堆叠语义](../../data-semantics.md#堆叠)；同组单位和统计口径一致且可加总，明确正负累积、缺失及Tooltip取值口径。
- 数据数量编辑、数据项编辑及随机、上升、下降趋势仅作为演示工具；使用时明确标注模拟数据。
- 其他Hover图形变化、Selected/Highlight样式、具体响应断点、复杂多系列密度策略及内部Token映射尚未完整定义；按任务补充并标为本次设计方案。空间自适应、柱宽和间距遵从本章已有规则，不再作为未定义项处理。
- 缩放轴没有统一启用数量阈值或独立Mini样式；需要时结合任务定义，不把案例参数写成通用规则。

## 公共样式

文字和网格采用[通用视觉规则](../common/visual-basics.md)，区域间距采用[布局规则](../common/layout.md)，系列颜色采用[颜色规则](../common/color.md)，小尺寸信息压缩采用[Mini布局规则](../common/layout.md#mini-信息压缩)。
