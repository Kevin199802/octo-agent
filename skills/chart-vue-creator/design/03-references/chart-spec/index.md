# 图表规范索引

先选择规范，再按图表类型读取。规范决定表达样式，不替代方法选择、数据语义与工程交付要求。

## 选择规则

| 条件 | 采用规范 |
| --- | --- |
| 用户明确指定规范 | 使用指定规范，包括半导体项目明确要求HD的情况；指定但未提供的规范不能被HD冒充，可说明采用临时方案 |
| 未指定规范，明确为半导体领域项目 | 半导体 |
| 未指定规范、领域不明 | HD |
| 明确为其他领域，但本包未收录对应规范 | 暂用HD，在交付说明中注明 |

领域依据用户需求和项目上下文，不从方法卡、示例数据或参考代码推断。不必为默认规范单独追问。用户的单次样式要求仅覆盖本次对应元素，不修改整套规范。

一次任务按所选规范读取；多领域页面按明确的模块边界选择并说明，不在单张图中无依据混用。半导体未定义部分不自动继承HD；确需参考HD时标为本次设计建议，或记录用户明确授权的继承范围。冲突先核对适用范围；未解决的条目说明临时处理，不宣称全部符合。

用户明确指定的跨图表通用组件单独加载，不属于HD回退。目前[桌面Tooltip](common/tooltip.md)适用于HD和半导体等本包图表；其卡内样式不改外层图例、标题、轴等领域规则，内部接入协议继续生效。真实冲突按前述选择原则记录差异与处理。

## 按需入口

| 读取条件 | 文件及范围 |
| --- | --- |
| HD | [HD入口](hd.md)，再读实际用到的通用/专项文件 |
| 半导体 | [半导体通用规则](semiconductor/general.md)；晶圆再读[晶圆专项](semiconductor/wafer.md) |
| 半导体内部组件接入、原型实现或工程交付 | [实现与接入](semiconductor/integration.md)：内部依赖和当前缺口；晶圆运行时仅在晶圆场景适用 |
| 半导体密集图形 / 快照参考 | 按任务读取[响应式专项](../methods/03/semiconductor-responsive.md)；复用算法或快照参考再按[03-5](../methods/03/adaptation.md)读资产。该专项不是领域样式规范 |
| 桌面端图表有Hover提示（不限图表类型） | [通用Tooltip组件](common/tooltip.md) |
| 新增或整理规范 | [结构](schema.md)与[模板](_template.md) |

工程HANDOFF记录实际采用的规范、可获得的标准版本、临时补充和未接入项；标准版本未知时注明未知，不以Skill版本代替。内部依赖及契约按对应领域的实现与接入规则处理。
