# 单文件 HTML 交付

仅用于用户明确要求单文件或离线HTML；网页原型的默认技术栈见[Vue/ECharts交付](vue-echarts-delivery.md)。图表选择、数据语义、规范读取与验收沿用入口流程。

- 提供可本地打开的文件，使用可用绘图库或HTML/SVG/Canvas；已有组件可复用时通过真实配置实现，不虚构内部依赖。
- 普通单文件可引用外部资源，但必须说明并检查依赖可用；明确要求离线时，将必要脚本、样式和资产合法内嵌或随包提供，不能仅用CDN链接声称离线可用。
- 半导体快照参考的读取与实现由[03-5](../methods/03/adaptation.md)路由，不因使用HTML自动加入整套截图工具。
- 按[生成与验收](generation-review.md)打开目标尺寸并操作承诺的交互；导出图片要确认文件实际产生。无法写文件时提供完整可保存代码并说明限制。

交付说明包括文件、启动/打开方式、必要依赖、示例数据与未验证项；无需展示内部规范清单。
