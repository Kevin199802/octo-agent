# Method 02｜评价与证据

## 内容与路由

来源、四组能力和共享规范边界可追溯；能推荐载体与所需交互，不扩成自动诊断。检查本次任务与相邻方法的边界，等级/优先级缺失不能伪造。

## 原型实际检查（仅生成原型时）

- 已定义异常可被找到且理由可查；颜色之外有数值/文字；无阈值时不生成确定异常。
- 阈值边界、原精度、缺失、无效和真实零处理正确；多指标不同单位不共享未经解释的原值风险色域。
- 筛选、排序、TOP N、并列及分页符合说明，统计范围不含糊；查看全部、恢复和详情返回实际可用。
- Wafer区域有坐标依据，概率有来源；缺接口、数据或性能证据标为待接入/未验证。
- 依承载环境记录编译、视觉与交互、导出及业务接入的真实证据。未要求的导出不强制增加。

FAIL：自造真实阈值/风险总分/因果、极值直接判异常、缺失当正常、局部排序冒充全量TOP、伪造区域或概率。未执行的任务标未验证，静态文档核对不算浏览器或独立Agent行为通过。
