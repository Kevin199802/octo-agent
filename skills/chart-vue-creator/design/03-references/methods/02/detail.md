# Method 02 Detail｜异常对象发现

## 输入与判断依据

先明确对象、指标及单位、时间范围、数据质量，以及异常依据来自业务规则、已有检测结果还是相对比较。来源不足时仅对关键歧义澄清；可用标注清楚的模拟数据完成原型，不要求内部源码，不伪造规则。

| 依据 | 能表达什么 | 不应推断什么 |
| --- | --- | --- |
| 已有阈值/等级 | 规则触发对象、等级与偏离值 | 未提供的风险级别、根因 |
| 相对高低/极值 | 当前可比集合内排名和关注项 | 业务异常或越大越危险 |
| 已有概率 | 对指定事件、时间窗的概率值及颜色 | 严重程度、确定发生；不能用Min-Max值冒充概率 |
| 已有检测结果 | 输入给定的标记及可查依据 | 未提供的检测算法、算法准确率或已确认原因 |

规则保留上下限包含关系、适用对象/时间和来源版本。按原始精度判定，显示取整不能改变结果；百分比差值用百分点。缺失、无效、未采集与真实零值区分，无法判定不纳入正常计数。具体数据处理遵从[数据语义](../../data-semantics.md)。

## 02-1 异常等级表达

业务已有等级时使用离散状态色配文字/符号；连续偏离强度可用有图例的渐变，但不凭色深新增风险等级。颜色规范从[规范索引](../../chart-spec/index.md)选择，不复制或另造状态色体系。具体Token或等级定义缺失时说明本次建议。

比较视图保持同一色域和阈值，筛选不默默重算；若用户明确改变参照范围，展示范围与变化。优先突出异常单元格与对象定位信息，正常背景弱化但保持可读，不整表强烈染色。

## 02-2 异常对象快速筛选

排序先说明依据：已有严重程度/优先级、同口径偏离量或单指标原值。没有规则时不合成多指标风险评分；不同单位、不同阈值下的原始偏离量不可直接混排。

TOP N是按选定依据的截取，不是新异常算法。说明N、筛选集合、并列处理及剩余数量，提供查看全部/恢复顺序。缺失项位置明确且可单独查看；相等项稳定排序。已有告警等级与偏离量冲突时遵从业务优先级，无优先级则提供分别排序，不自定权重。

全量排序后再分页，或明确“当前已加载数据”范围；服务端排序/筛选必须有真实接口，不能只排当前页却称全局TOP。数量摘要说明对应基础集合还是筛选结果；同一对象多项命中时区分对象数与命中项数。

## 02-3 多维异常定位

对象×指标或对象×时间可用热力矩阵；保留行列名称、原值和异常依据。单位不同按列提供独立色阶/规则，不能把原值大小跨列解读为风险高低。无规则仅表达数值分布，不标业务异常。

Scatter适用于已有两个数值维度或真实空间坐标，保持身份可追踪；孤立点不自动算异常。Wafer区域定位要求有真实/明确模拟的die或zone坐标；仅有Wafer汇总良率时只定位Wafer，不能编造片内缺陷区域。必要时保留总体分布并高亮已定义异常。

聚合/采样不能静默隐藏已知异常；说明聚合口径和是否保留异常明细。大数据性能以实际规模测试为准，不以少量示例宣称支持海量。

## 02-4 异常详情联动

对象选择传递稳定ID、当前指标、时间范围与筛选上下文。详情显示原值、规则、触发原因及数据质量；返回后能恢复选择和筛选。过滤/删除掉选中对象时清理或明确说明详情状态，不保留无说明旧内容。

趋势观察转01、关系/原因线索转04、事件记录回顾转06；分布查看按输入数据和已有能力实现。外部跳转、后台查询和跨模块上下文传递仅在有真实接口时实现；否则提供本地详情并说明待接入，不假称持久化或已联通。跨模块传递与分析保存仍分别归13/12。

## 载体选择与工程

| 载体 | 选择条件 |
| --- | --- |
| Table/状态列表 | 找对象并精确读取原值、等级、原因；首选宿主表格组件，不强制画到ECharts中 |
| Heatmap/条件染色矩阵 | 扫描对象×指标/时间的分布；语义与色域必须可解释 |
| Scatter | 有两个数值变量或真实空间坐标，需要定位已标记对象 |
| Pareto（辅助） | 已知异常类别的数量/影响贡献；主任务变为找主要贡献类别时走08及其当前状态，不拿贡献占比当对象风险 |

选定方法不意味着四组能力全上。推荐输出为“问题判断→主方法及依据→载体→所需能力/交互→原型方向与数据缺口”；只解释本次相关部分。工程遵从[承载工程规则](../../prototype/hosted-project.md)及[Handoff](../../prototype/handoff.md)，ECharts能力或内部组件未知时如实说明，不绕过管道或另起默认工程。
