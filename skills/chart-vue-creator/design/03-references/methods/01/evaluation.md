# Method 01｜趋势洞察增强模式｜验收

只检查任务要求或方案承诺的能力；不把平滑、缩放、多线聚焦同时作为所有趋势任务的必需项。

| 范围 | 通过条件 |
| --- | --- |
| 任务 | 区分整体方向、波动/稳定性与局部异常 |
| 平滑（使用时） | 处理口径可解释，保留原始数据；几何平滑不称降噪 |
| 局部观察（使用时） | 范围明确，可恢复；框选时有实时反馈及取消处理 |
| 多曲线（使用时） | 身份稳定，重点可辨；弱化不改变数据或参照口径 |
| 预期与基线（使用时） | 示意、历史结果、目标与平滑分别标识；比较条件有据，不强制虚线 |
| 安全区隐藏（使用时） | 有异常才折叠；按业务定义隐藏安全区，未另行定义时采用正文默认方向；上方开关与Y轴展开一致，保留原值、双侧数据和折叠提示 |
| 实时局部观察（使用时） | 历史窗口不被新数据无提示推走，跟随最新可恢复；Y域口径明确 |
| 数据与规范 | 原值、单位、时间和异常可理解；适用视觉规则落实 |

主方案正确但承诺交互未完成可判PARTIAL；原始数据不可恢复、伪造异常阈值或将个案参数说成通用规范判FAIL。仅给建议时不声称浏览器行为已通过。案例见[示例](examples.md)。

## 安全区隐藏边界用例

以下是待执行预期，不是运行结果。数字仅为模拟用例，不成为业务阈值或视觉规范。

| 场景 | 可观察结果 |
| --- | --- |
| 单阈值T=80，默认上限语义（大于80异常），值为60、80、100 | 开启后隐藏80以下区间，100仍可见，80边界可查；Y轴80处可展开，恢复60且关闭开关 |
| 单阈值T=80，业务定义小于80异常、80及以上正常，值为60、80、100 | 开启后隐藏阈值上方安全区，异常值60保留，80边界可查；Y轴80处可展开并恢复100，异常归属及原值不变 |
| 双阈值L=40、U=80，值为20、40、60、80、100 | 中间安全区隐藏，上下20与100都保留；40与80边界及展开入口可辨，任一展开恢复全区间 |
| 相邻时点从20跨到100 | 跨界处断开/裁剪且折叠提示可辨；不伪画普通直线，不改变X轴时间和原始值 |
| 全部有效值在安全区；另有缺失项 | 保持完整线性Y轴与原始数据，不折叠、不出现展开入口；提示有效数据无异常，缺失单独计数，全缺失不报正常 |
| 无阈值、L≥U、多个阈值角色不明 | 过滤不可用并解释，不自造安全区或擅自挑两条线 |
| 开启后调整容器、更新数据/阈值或缩放时间 | 依异常是否存在重算或移除折叠与展开入口，不残留旧位置；阈值失效时恢复完整尺度并关闭开关 |
| 点击展开与手动关闭开关 | 均恢复完整区间，保留当前X窗口和对象选择；重新开启不丢原数据 |
| 导出折叠图（要求导出时） | 图片保留阈值与折叠含义，不能仅依赖未被导出的DOM标签 |

原始记录丢失、双侧异常被裁掉、折叠斜率冒充原始变化量、开关/展开不同步均需修正。

平滑调节需检查默认/最小/最大、连续往返、关闭再开及多系列；最小挡位检查原始数据直通且算法未执行，不仅观察两线重合。原始/处理层分别显隐、同时间Tooltip及无匹配反馈需实际验证。共享Limit分别验证范围/单位/版本/生效时间相同与不同的数据。
