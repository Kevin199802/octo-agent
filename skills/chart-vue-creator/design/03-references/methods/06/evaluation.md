# Method 06｜验收

只检查本次任务要求和方案承诺的能力。

| 范围 | 通过条件 |
| --- | --- |
| 任务与输入 | 需要过程回顾，并有时间、对象和事件内容；缺记录时明确证据缺口 |
| 时间轴 | 关键阶段、重叠事件和缺失区段表达正确，不强造线性因果链 |
| 节点 | 事实、指标变化观察和待验证解释可区分；恢复有记录或判定依据 |
| 前后比较 | 时间窗、单位、统计口径与样本范围可比，缺失不补0 |
| 记录与输出 | 保存/恢复按真实宿主能力表述；静态图直接保留核心证据 |

伪造事件/恢复、以先后顺序证明因果、声称不存在的持久化功能判FAIL。仅检查本次使用能力。
