# Method 04｜指标关联分析模式｜详解

先确定对象或变量、每个指标的单位和方向、观察窗口，以及用于跨图对应同一对象/事件的键。关系图展示观测关系；若要解释影响因素，区分已确认机制、待验证假设和图中相关性，不能仅凭拟合线写成因果结论。

## 04-1 指标同步观察

目标：观察多个指标随时间变化的同步关系。

能力：
- 共享时间轴
- 趋势对齐
- Hover同步定位
- 时间范围联动

推荐：多折线图、上下趋势组合图、特殊场景双轴图。

执行时先对齐时间戳、时区、采样粒度与缺失区间；不同采样频率需说明重采样或聚合口径。同步 Hover 只在有对应时间/事件记录时显示值，不用邻近点伪装精确同时发生。静态输出直接标出关键时段和单位。

- 04-01：选择依赖稳定业务键；明确过滤是交集、覆盖还是仅高亮。双向更新使用同一次选择事务避免循环；无匹配显示反馈，可清除选择，未关联图不误过滤。

## 04-2 指标关系探索

目标：探索两个指标之间是否存在关联趋势。

能力：
- 指标关系映射
- 数据分布观察
- 趋势拟合辅助
- 异常点识别

推荐：散点图、散点+趋势辅助。

每个点保留对象/样本身份与 X/Y 原值。拟合需要真实样本、可解释方法和残差/异常点检查；样本不足或关键变量缺失时展示原始分布并说明结论边界。变量先后顺序或相关系数不自动证明影响关系。变换与拟合边界见[数据语义](../../data-semantics.md)。

- 04-04：X/Y来自同条记录，缺一维明确排除或提示；不随意jitter真实坐标，重叠用透明度、密度或筛选。ModelArts案例X为Val Loss而非Train Loss、Y为算力消耗，每点一次训练任务，仅该案例适用。

### 双指标目标空间与时间演进

明确每个点代表任务、评测还是同一任务的时间样本，保留稳定ID。X/Y指标标单位及业务方向；Loss与算力消耗需注明算力是瞬时、累计或其他口径。历史基线点标来源、可比条件，目标区域来自期望约束，二者不能互相冒充。目标可为联合条件，不默认矩形或左下角最好；无目标依据时展示原始分布，不自造达标区。

时间顺序可用有时间图例的渐变，并提供可辨的起止点标记；真实连续轨迹可按需添加连线或箭头。同一对象的有序记录才连接为轨迹，缺失区间不伪装连续；独立任务不能随意连成时间演进。颜色编码时间时，不再同时含糊地表示对象或严重度；多对象可借标签、符号、分面或选择聚焦区分，具体样式沿用适用规范。颜色随时间变化属于合法数值编码，不取消其他视图的分类身份映射。

- 04-05：历史基线为具体记录，附时间/版本与单位，不以样本均值冒充；目标来自业务配置，缺哪维边界就不补造，单维约束用单轴区间，不强画二维矩形。基线用独立标记，目标用不遮点的区域或边界，含义可辨。

- 04-06：时间按真实时间戳排序，图例明确早晚；ModelArts浅早深近。无可靠时间戳不生成渐变；时间编码不等于优劣或风险。分类色已占用时改用起止标记、分面等通道。

需要从点进入记录时组合04-3；任务变为多个独立对象的多指标优劣时转05，不只凭散点或指标列数判路由。华为云是案例来源，不自动引入一套新的领域视觉规范。

## 04-3 多视图关联定位

目标：通过多个分析视角定位异常原因。

能力：
- 图表联动
- 选择过滤
- 关联对象高亮
- 下钻分析

典型分析链路：
趋势 → 分布/空间 → 原因定位。

跨视图选择需要稳定对象键，明确选择、筛选和恢复时哪些图跟随更新；对象无法关联时不要假装完成联动。诊断可以提出待验证原因，但未有证据时不能把它标为已确认根因。若目标是按真实事件记录还原发生、演变和恢复，主方法转06。

### 图表与表格定位

通过稳定业务ID关联，不使用当前行号或排序下标。选中点后定位或高亮对应记录，保留原值、单位和当前选择；表格排序、分页后仍定位同一对象。记录被筛掉、删除或尚未加载时说明情况，按真实能力提供显示目标/加载入口，不能静默改筛选或高亮另一个同名对象。多时间样本对应同一任务时用任务ID与样本时间等实际键区分。

- 04-07：点击点才定位记录，Hover不自动跳页；选中态与悬浮态区分，清除选择同步清除点/行。跨页按ID定位，一对多明确成员数；虚拟列表用真实定位能力，不全表扫描DOM。双向联动按任务可选。

本页联动由本方法处理；保存现场和跨模块继续分析转10及其当前状态。接口未知时实现可核验的本地演示，并列出所需接入契约，不伪称真实系统已联通。
