# Method 04｜指标关联分析模式｜验收

按本次任务选择的分支检查。

| 范围 | 通过条件 |
| --- | --- |
| 路由 | 同步04-1、关系04-2、诊断04-3；不把对象比较或事件回顾混入主任务 |
| 同步观察 | 时间戳、时区、采样与缺失对齐有据；近邻值不伪称同时发生 |
| 关系探索 | 样本身份和X/Y原值可查；拟合口径与结论边界明确 |
| 联动诊断 | 通过稳定对象键联动；选择、筛选、恢复范围明确并实际生效 |
| 目标空间与时间演进（使用时） | 基线和目标来源、指标口径可辨；轨迹连接同一对象有序样本，时间颜色有图例 |
| 图表与表格（使用时） | 排序/分页后仍按稳定ID定位；隐藏、未加载或删除目标不误选其他行 |
| 证据 | 相关观察、原因假设与已确认机制可区分 |

仅检查使用或承诺的能力。伪造关联键、把拟合当因果或把无效联动称完成判FAIL。

矩阵04-01/04/05/06/07分别验收：无匹配与双向联动循环；X/Y单记录配对及缺失；单维/二维目标和历史基线独立；早晚方向及起止标记、独立任务不连线；点击定位跨页/排序/筛选/虚拟列表，Hover不跳页、取消选择恢复。
