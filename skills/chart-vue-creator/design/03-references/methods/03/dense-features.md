# 03-4｜密集图形特征提炼

保持原载体的统计语义，减少遮挡，使分布和关键特征可见。

| 图表与问题 | 能力及阅读 |
| --- | --- |
| 少箱（当前可见箱体N≤5）散点压叠 | 保留箱体/统计摘要，背景点用纵向排列的水平圆头密度短条表达；不是回归线或小提琴填充 |
| 多箱（N>5）趋势难辨 | 保留箱体、连接中位数，隐藏普通点而保留异常点；N不是样本数或PPT图数 |
| 多折线点标记压叠 | 保持点位与数据，弱化线并采用峰谷横/其他竖短标记；近竖直修正为业务扩展，非平滑 |
| 散点重叠 | 按组聚合/密度表达；参考气泡为相对密集程度，非面积正比或概率面积 |
| 热力区域轮廓不清 | 连续数值网格按色阶形成等高线，保留色块/色标；非单元格描边，原HTML未包含 |

执行以上半导体分支时读[专项规则](semiconductor-responsive.md)，遵守其中的统计含义、参数适用范围和N边界。需要复用参考图形代码或忠实复现时再读[演示对照](reference-demo.md)及对应完整HTML；普通方法建议不必加载HTML，单独图形优化不自动生成截图窗口。

聚合、密度、拟合处理须读[数据语义](../../data-semantics.md)。无样本不能由箱形摘要伪造真实密度；只有热力截图不能反推出真实网格。原始值、组身份、异常信息保持，转换口径须可解释。

500/430是具体配置，只有参考截图或已确定业务适用时使用；其他尺寸按当前容器和可读性制定本次建议。报告多图可组合03-5，不把每张图替换成Sparkline。

## Mini折线特征筛选

需要短标记表达时，峰谷使用短横线，其他保留的采样点使用短竖线；短竖线接近局部屏幕曲线方向而难辨时改横线，缩放后重算。标记仍对应真实时间与原值，不以平滑代替标记变换。

候选峰谷结合显著性、最小间距、采样密度、噪声及实际像素宽度筛选，邻近不可辨候选合并或保留更显著者；不能标注每个局部抖动，也不能丢掉业务关键异常。阈值来自业务配置或经验证的自适应策略，无依据不写死数值。缺失分段处理，可靠性不足时减少标记而不下确定性结论。

此规则面向新生成的Mini表达；半导体参考HTML的严格局部极值与固定尺寸是参考实现，不宣称其已实现本筛选能力。忠实复现参考时明确差异；生成新版能力需补实现，不能将参考尺寸推广到其他图表。
