## 先读实物，再实现

原始资产：[semiconductor_yield_dashboard.html](../../../04-assets/method-03/semiconductor_yield_dashboard.html)。这是用户提供的参考，不是已验证的生产工具。生成快照参考分支或复用其算法时读取完整文件，并结合[窗口交互](snapshot-detail.md)与[图形规则](semiconductor-responsive.md)。复用交互结构和可解释算法，按当前目标技术栈实现：默认Vue/ECharts需实现为Vue组件与ECharts图形，不能直接把React/D3依赖带入并声称符合默认交付。

文件依赖Tailwind CDN、React18/ReactDOM、Babel standalone、D3v7；依赖可用时才能打开运行，不声称离线单文件无依赖。演示数据在模块初始化时随机产生，同一次页面中共享；重载会变。生成可比较的验收原型时建议固定seed或内嵌固定样本，并注明示例数据，拖动时不重新造数据。

以下整页结构仅约束快照参考复现；单独复用图形算法时不强制引入五标签和窗口。

## 视觉结构约束

| 部位 | 源码依据与复用要点 |
| --- | --- |
| 页面 | 浅灰背景，顶部居中标题与右键提示，主卡片白底、细灰边、圆角、轻阴影，宽上限约1024px |
| 标签页 | box 1 / box 2 / line / scatter / bar；激活项白底、蓝色文字和顶部细蓝线；不要变成KPI卡阵列 |
| 主图 | 宿主高600px，SVG轴/浅网格/右侧图例，给大图和快照同一渲染组件 |
| 右键菜单 | 光标附近小型白色圆角菜单，相机图标和“截图”；不是侧边编辑器 |
| 快照 | 白色非模态浮窗、细边框和明显阴影；浅灰标题栏、尺寸文本、原貌开关与关闭；窗口不遮罩锁死主图 |
| 图内留白 | 轴标题、旋转标签和右侧图例分别预留空间；优先保留原图密度和短条形态，不能只画几条示意线 |
| 小图对照 | 同一尺寸切换优化/原貌，原数据身份不变；这是展示设计效果的重点 |

数值常量与图形细节以 [响应式规则](semiconductor-responsive.md) 为准。上述是参考的结构与层级，不要求把示例业务标题照搬到别的业务；既有默认分类色板仍有效。

## 代码定位

| 源码标识 | 做什么 | 复用或泛化注意 |
| --- | --- | --- |
| generateDistributionData / datasetBox1 / datasetBox2 | 生成箱形摘要与原始样本、4组设备和23片wafer | 真实输入时替换数据层，保留稳定原样本 |
| ResponsiveChart | 统一SVG渲染与轴更新 | 布局响应与图形响应独立 |
| isLayoutSmall / isLayoutShort | 宽/高布局断点 | 不受forceDefault控制 |
| shouldAggregateBox1 | 分箱水平圆头短条 | 按当前N泛化时补N≤5分支 |
| shouldShowMedianLineBox2 | 中位趋势线和异常点 | 原貌保留完整点，N>5 |
| isLineNarrow | 弱化连线、峰谷短横条/其他短竖条 | 陡斜率修正未实现 |
| isScatterNarrow / renderScatterData | XY网格内按组聚合的气泡 | 非线性半径，不是概率面积 |
| DraggableWindow / forceDefault | 拖动、三方向resize、同尺寸原貌 | 不是恢复全部初始设置 |
| handleContextMenu / handleTakeScreenshot / screenshotWindows | 菜单、创建多快照与关闭 | 不包含PNG/剪贴板图片生成 |

## 已演示与扩展分开

| 能力 | 附件源码状态 | 当前实现要求 |
| --- | --- | --- |
| 右键新建快照、多窗口、拖动/缩放、原貌开关 | 源码已实现 | 参考基线必需，实际生成后仍需运行检查 |
| 少箱短条、多箱中位趋势、折线标记、散点气泡、柱图 | 源码已实现 | 保持对应形态与数据含义 |
| 字体全面连续缩放 | 未实现；仅标题字号与刻度布局变化 | 不夸大附件功能，可按请求补充 |
| 点大小/透明度/边框面板、独立拟合选择 | 待补充；附件未实现 | 明确请求时新增轻量入口 |
| 近竖直折线标记修正、热力等高线 | 待补充；此前业务需求仍保留 | 按专项规则实施，不伪装附件已含 |
| PNG导出/剪贴板 | 待补充；附件“截图”仅新建快照 | 要求实际图片时实现并检查文件 |
| 菜单边界、窗口置顶、狭窄视口与键盘访问 | 附件不完整或未覆盖 | 合理增强，说明为当前实现建议 |

不得用“已实现”指代本包在内部Agent已验证。这里的状态仅指源代码包含对应逻辑。

## 实现顺序

1. 按目标技术栈实现主图卡片、标签和窗口结构；连通右键创建、移动、resize、关闭。
2. 保留统一图表组件，接入原样本和选择的尺寸配置。
3. 实现对应优化图形及原貌开关，同尺寸核对两种形态。
4. 补轴布局、图例、必要单位，使用通用色板；按请求增加扩展。
5. 按 [专项验收](snapshot-evaluation.md) 核对；不能仅凭代码包含函数名就写“交互测试通过”。
