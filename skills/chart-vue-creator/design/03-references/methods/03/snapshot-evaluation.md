# Method 03｜半导体截图分支验收

先确定请求为参考基线、明确业务配置或扩展。下列为验收预期，不是通过证据；记录每项“通过/失败/未执行/不适用”及实际观察。

| 范围 | 检查 |
| --- | --- |
| 路由与阅读 | 仅评03-5半导体快照参考分支；读取原始HTML及方法详细规则；普通Yield概览按03总体验收 |
| 视觉基线 | 主图卡片/标签、轻量右键菜单、非模态浮窗、清晰轴与图例；不是KPI卡或全屏编辑器 |
| 核心交互 | 右键新建快照、移动、三方向resize、关闭；多窗口图表类型与状态独立 |
| 配置边界 | 默认499/500优化、501完整；明确430配置时429/430优化、431完整；不得混用 |
| 原貌 | 相同尺寸恢复原图形，位置不变、轴布局继续响应；再关回优化；无随机换数据 |
| 少箱 | 分箱水平圆头短条长度编码组内相对密度，保留箱体，不是回归/中位连线 |
| 多箱 | 连接中位数、隐藏普通点、保留异常点；推广按当前N=5/6分支 |
| 折线 | 线变淡、峰谷横/其他竖标记；新原型图例按公共规则，明确忠实复现时才随源标记；近竖直修正按扩展范围单独查 |
| 散点 | 按组网格聚合、描边半透明气泡；非线性半径不声称概率或面积正比 |
| 布局 | 宿主宽高、标题/刻度/标签分开响应；默认浮窗400下限不假称可拖至399 |
| 样式扩展 | 请求时实际调整，拖动保留覆盖，原貌对照不重置窗口 |
| 热力扩展 | 请求时用数值网格与色阶形成等高线，不冒充附件已有 |
| 图片扩展 | 请求时实际生成当前状态文件；输出倍率不改变分支，无工具层，不伪报成功 |
| 数据与规范 | 原值、单位、稳定身份；通用色板；缺规范不阻止载体选择；反馈非实测 |

参考基线缺少未请求扩展不判失败；明确请求扩展则必须完成对应检查。源码存在某函数不等于拖动、渲染或导出已通过；没有浏览器运行证据就标未执行。只有静态图、无效按钮或窗口拖动位置而不能resize，不能视为核心链路完成。

旧版评价未随包分发，不参与当前裁决。
