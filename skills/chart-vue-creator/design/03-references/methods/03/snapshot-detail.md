# Method 03｜半导体截图分支 Detail｜以演示为依据的窗口交互

本文件只在03-5的半导体快照/截图分支适用；普通概览、单纯样式调节不加载整套窗口流程。

## 1. 先确定交付范围

默认完整演示采用附件的主图与浮动快照结构，见 [实现对照](reference-demo.md)。保留当前用户的图表与分析语义。普通概览不自动增加截图工具；明确要本方法则不能以概览代替。

区分三个范围：①附件基线：右键启动、浮动快照、拖动缩放、图形优化、原貌对照；②原有业务扩展：样式微调、热力等高线等；③实际图片导出。用户要哪个范围就完成哪个；“参考附件演示”默认①，明确要求导出 PNG/放报告文件时加入③。不能把①的快照窗口描述成已生成图片文件。

## 2. 源图与快照窗口

1. 源图放白色卡片，图表标签位于顶部。图内右键打开小菜单，项目为“截图”，点击后关闭菜单并创建快照。
2. 快照是非模态浮动窗口，原主图保持可操作，没有遮罩。窗口保留创建时的图表类型与数据身份；切换主图标签不改变既有快照。
3. 标题栏显示图表名和当前宽×高，可拖动位置；右侧是“原貌图形”开关与关闭。开关/关闭不触发拖动。
4. 右边、底边、右下角分别调整宽、高、宽高；不把“拖动位置”当成调整大小。
5. 支持多个独立快照，移动、缩放、关闭和原貌状态互不干扰。
6. 采用参考默认初始600×400、最小400×300；图表宽W取实际图表宿主内容宽，高H排除标题栏。原始实现传入width=size.width、height=size.height-40；复用时应测量实际标题栏，避免固定减40导致溢出。

合理健壮性补充：菜单/窗口限制在可见区域，激活窗口置顶，标题栏保持可抓取；这是本次建议，不是附件已有能力。小视口不足400px时允许明确的适配覆盖或滚动，不静默裁掉操作入口。键盘/触屏可增加可见“截图”按钮，保留右键主入口。

## 3. 状态拆分与原貌语义

分别维护数据/图表类型、窗口位置尺寸、布局计算、图形模式。数据只初始化或在用户换数据时更新，拖动与切换不能重新随机生成。

| 事件 | 图形状态 | 窗口与轴布局 |
| --- | --- | --- |
| 创建快照 | 默认自动优化策略 | 新建独立窗口 |
| 小尺寸，原貌关闭 | 当前图表的优化图形 | 按实际W/H计算 |
| 小尺寸，原貌打开 | 原始散点/圆点/原始箱形表达 | 尺寸位置不变；标签旋转、抽稀仍有效 |
| 继续拖动 | 保留显式原貌选择 | 重新计算W/H与布局 |
| 放大越过图形阈值 | 完整图形；原貌开关可隐藏 | 仍自适应 |
| 再缩小 | 保留该窗口之前原貌选择 | 不重置尺寸 |
| 关闭一个窗口 | 只释放该快照 | 其余窗口、主图不变 |

“原貌图形”是可开关的同尺寸对照，保持窗口尺寸。如另有“重置所有设置”，使用独立名称，并明确重置哪些参数，不能取代原貌开关。

## 4. 图形与布局分别响应

图形优化依赖宽度和原貌开关；轴/文字布局只依赖实际宽高。尺寸配置与图形细节只在 [响应式规则](semiconductor-responsive.md) 定义。缩小不能只是缩放整个SVG，也不能为了显示趋势换掉原始图表。

标题、轴标题、图例保持可读。参考通过标题字号、标签旋转、刻度抽稀和图形替换减轻拥挤，不能声称它已实现所有X/Y轴字体的连续缩放。若补字号响应，使用明确当前建议，不让字体无限缩小；优先减少重复信息而保留必要单位。

## 5. 按请求增加元素微调

附件没有点大小/透明度/边框面板。需要时使用标题栏轻量“元素”入口或小型弹出面板，不默认重构成常驻宽侧栏。仅给当前图表适用控件：点大小、透明度、边框、原始/聚合模式；“拟合”须说明对应密度还是回归，不虚设无作用按钮。

扩展状态优先级：用户显式参数覆盖高于自动默认；拖动保持覆盖。“原貌图形”打开时暂用该数据初始图形样式，保存而不删除微调配置；关闭后恢复此前优化/微调状态。若提供“重置样式”，只清除样式覆盖，尺寸位置仍保留。此协调是本次扩展建议，附件仅有forceDefault布尔开关。

## 6. 实际图片输出（明确请求时实现）

窗口中的“导出PNG/复制图片”与源图“截图”分开。输出当前图形模式、必要轴/标题/图例，排除窗口标题栏、菜单、手柄、编辑面板及Hover。倍率只改变像素清晰度，不能改变CSS断点或重算成大图。复制受限时可下载；只支持SVG就明确标注SVG，文件实际产生后才提示成功。

最终放报告是静态图像，但准备过程仍可交互。未请求导出时不因附件没有下载而否定参考复现；已请求导出时不能交付快照窗口后声称全部完成。

## 7. 检查与来源

按 [当前检查](snapshot-evaluation.md) 记录实际执行范围。结构检查不能替代视觉、拖动和导出运行验证。用户报告约2分钟至约10秒是来源反馈，保留“约”和来源，不宣称本包实测。缺算法可选择可解释实现；缺原始样本不能伪造真实密度，必要时用明确标记的示例数据。
