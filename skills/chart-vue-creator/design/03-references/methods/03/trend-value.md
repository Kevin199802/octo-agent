# 03-3｜趋势与关键数值协同表达

来源：原11趋势与数值兼顾；数字能源Mini图表的时间提示、柱线组合、告警与占比；开发者快速看走势后查看具体值。

- 当前值负责回答“现在多少”，趋势回答“期间怎么变”；明确数值对应的时间、单位，避免将最新值与期间累计值混写。
- 按用户关注标记关键点与数值，保留必要时间点/区间。不要给所有点加标签而重新制造拥挤；关键点选择需有业务或数据依据。
- 柱线组合只在两种编码确实分别表达所需信息时使用；说明指标、单位和对应关系，不为“信息增强”任意添指标或双轴。
- 告警使用已有状态定义；与告警占比配合时注明分母与统计时间窗。没有占比数据不能由颜色反推比例。
- 当前值+趋势可以是最小方案；用户需要告警、分布等时再加入对应信息。静态报告不依赖Hover暴露核心数值。

异常高亮、阈值线是可扩展做法；使用用户提供/已存在的阈值，不把未知阈值补成真实业务规则。不自动切换为趋势平滑；需分析震荡中的走势时组合01。
