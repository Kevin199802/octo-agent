# Method 03｜半导体截图分支｜响应式图形与布局规则

本文件集中维护半导体图形参数。参考字号、图例、边距仅用于解释源码；新原型的公共元素按[所选领域规范](../../chart-spec/index.md)实现，特殊尺寸取舍需说明。


本文件是尺寸和图形参数的唯一详细定义。来源有两类：用户原先的业务描述，以及新增HTML演示。附件里的数值是可复用原型参数，不是所有业务的通用规范。

## 1. 明确选择尺寸配置

| 配置 | 使用条件 | 图形优化条件 |
| --- | --- | --- |
| reference-demo（默认） | 参考附件、默认演示Method 03｜半导体截图分支、未另指定阈值 | W≤500 CSS px，且原貌关闭 |
| semiconductor-430 | 用户明确要求原430px规则或沿用该已确定业务配置 | W≤430 CSS px，且原貌关闭 |

只有半导体参考截图演示默认采用500；普通03概览或其他业务不继承此默认。该分支参考附件优先，因此默认演示采用500；不删除430业务规则，也不把两者同时用作同一实例的图形阈值。当前请求明确指定的断点数值优先；输出尺寸不自动成为断点。例如“420px宽报告图”仅设宿主宽度，参考配置仍用500px；明确“优化断点420px”才覆盖阈值。交付说明写明选择一次即可，不把内部配置名塞入产品界面。

W为直接承载图表的宿主内容宽度，含轴与图例空间，非viewport、扣除margin后的innerWidth或导出物理像素。H为图表宿主高度，不含窗口标题栏。窗口标题显示外层窗口尺寸时，不把它错误当成H。

参考布局规则独立于图形阈值与原貌开关：W<400时标题16→12px、多箱须线简化；H<350时Y轴在默认约8个刻度中隔项显示。边距参考top40/right120/bottom90/left60。分类可用带宽=innerWidth/类别数：<60px旋转标签-90°，<14px再按ceil(14/带宽)抽稀。散点X轴刻度数约max(2,floor(innerWidth/60))。这些为参考默认，可按真实标签长度补充调整，保持轴语义。

参考窗口最小宽400，因此W<400布局分支无法通过默认浮窗宽度拖动触发；需用主图窄宿主或明确的测试夹具检查，不能假报浮窗能拖至399。H为图表高度，600×400窗口在减去约40标题后H约360，不能直接把外窗400与350比较。

边界：默认图形499/500优化、501完整；430配置429/430优化、431完整；布局399触发/400不触发；高度349触发/350不触发。布局变化不应被原貌开关关闭。跨阈值来回可逆，源数据和数值域保持稳定。

## 2. 少箱 N≤5：水平圆头密度短条

参考box 1有4组设备、每组400个示例样本。小尺寸保留箱体、四分位/中位线、须；背景离散点替换为沿Y方向排列的**多条水平圆头短条**，每条中心对齐箱体，各高度条长体现当地样本密集程度。不得替换成光滑回归曲线、小提琴填色形状、连接中位数或固定等长装饰线。

参考可直接复用：每组用d3.bin在共同Y轴域按thresholds(35)分箱（目标阈值数，不保证恰好35箱）；忽略空箱。局部最大箱计数m，各箱计数c，条宽=max(4,c/m×箱体宽×0.7)，条高=clamp(分箱像素高度×0.85,2,8)，圆角=条高/2，填充透明度0.8。箱体宽=min(60,bandwidth)，箱体填充透明度0.45、描边1.5。

### 新原型分箱策略（v0.4.8确认）

以上35阈值/条高公式仍用于理解原始参考HTML，源资产不改。新原型出现纵向过疏时默认采用B；业务需固定分箱口径或忠实参考时采用A，用户选择优先，不同时叠加两种统计口径。

- **B 按绘图区高度选择分箱（默认）**：以扣除轴/标题后的有效绘图高度决定目标分箱数，使用共同Y数据域和各组一致分箱边界。可从约6 CSS px的目标条带间距起步（280px高约46箱），采用合适的等宽数据区间；这些是可调起点，不是硬性视觉规范。沿用短条相对计数映射与圆头形态，条高小于条带间距，空箱保持空白。样本很少时不机械增加分箱，避免把离散噪声表现为精细结构。
- **A 保留分箱、适当加厚（备选）**：不改变已有分箱边界和计数，仅调整条高及其上限，且不跨入相邻条带。预览中的8→10px仅是试调示例，应结合实际条带间距，不强制增加至10px。
- 不改原始样本、箱体统计量、Y数据域和对象身份。原貌切换使用同一批样本，不重新随机生成；空箱不能用装饰短条补齐。
- 不同高度重分箱会改变分布细节；需要跨图精确比较或固定报告口径时锁定共同分箱边界（采用A）。交互调尺寸时只在合适时机更新分箱，避免每个像素触发跳变；同一尺寸往返结果确定。
- 各组按自身最大计数归一化仍只表示相对密集程度；不从跨组或跨方案绝对条长推断样本量/概率。比较方案时使用同样本、同域与同高度。
- 在目标420px宿主和不同绘图区高度检查短条可辨、空隙合理、无相互覆盖，并保留异常/统计信息；未通过真实样本检查不能仅以“更密”声称更准确。

这是分箱相对密度表达，不是统计回归拟合。每组按自己的最大计数归一化；不能凭不同组的绝对条长比较总体样本量，也不能把条长称为概率。需要跨组定量比较时另采用共同标尺并说明取舍。缺样本只可保留摘要箱体或明确使用示例样本。

### 已确认四箱体Vue案例的覆盖参数

仅用于本轮已确认的640→420px四箱体案例：原始点覆盖在箱体上层且中心对齐；jitter总跨度为箱宽70%（中心左右各35%）；密度短线最大宽度等于箱宽；点默认直径8px、透明度70%，允许按界面控件调节。这些值覆盖该案例的参考几何/点样式，不替换原始HTML参数，也不自动成为其他领域规范。分箱语义仍按上文执行。复用案例后仍需按当前任务验证。

## 3. 多箱 N>5：中位趋势+异常点

参考box 2为23片wafer、每组100个示例样本。小尺寸保留箱体，连接相邻箱体的中位数median，线宽2、透明度0.8；隐藏箱须范围内普通点，保留小于min或大于max的异常点。原貌模式恢复全部原始点，关闭中位趋势连接。

本附件已明确“箱体中轴线”用median，不再写成完全未知。用户已有图表另定义统计位置时沿用并说明，不把均值与中位数混用。min/max来自样本极值与1.5IQR围栏裁限。异常点不应为减少拥挤而一概删除。

推广时N为当前同图可见箱体数，N=5与6是分支边界；附件按box 1/box 2固定类型实现，不能声称其已有动态N判断。泛化生成需补实际N判定，不按样本数或报告图数分支。筛选后重新判断N，但不重新分色或重算数据域。

## 4. 折线：保留线位，改为短标记

参考有2组序列、每组26点。小尺寸line保持坐标、线宽2但透明度降至0.4；局部严格峰谷用6×1.5px横短条，其余用1.5×6px竖短条；大尺寸圆点r4、连线透明度1。忠实复现参考时图例同步显示相应标记；新原型按公共图例默认或折线备选标记，必要时增加清楚的说明，不能把参考标记形态声称为公共图例规范。参考首尾点按缺邻居条件判断，平台相等点不会被严格峰谷规则标记。

此前业务要求“竖标记与局部line方向接近则改横标记”仍保留为扩展，但附件没有实现。明确要求此扩展时，基于当前屏幕坐标计算邻近线段与竖直方向夹角，接近时改横线；阈值属于本次实现参数，重新缩放后重算。不能用原始不同单位ΔY/ΔX判断视觉角度，不以平滑数据代替标记变化。缺失值分段处理，不制造跨缺失连线。

## 5. 散点：分组聚合、半透明描边气泡

参考3类器件各150个点。小尺寸在XY数据域用d3.ticks目标15与12导出网格步长，按网格+组身份聚合，气泡中心取组内格点均值；各组不合并。原始点r4、填充透明度0.7；聚合气泡填充透明度0.15、描边1.5，大气泡先画以减轻覆盖。

参考半径：minR=1.5；maxR=max(12,min(格宽像素,格高像素)/2×1.8)；全局格最大计数m=1时r=minR，否则r=minR+(c/m)^1.5×(maxR-minR)。该非线性放大用于突出密集区域，**不是面积正比、概率面积或可从面积精确读数量的编码**。复现时保留视觉效果并解释为相对样本密集程度；需定量读数可补计数提示/大小图例，或另改面积正比方案并明确已偏离参考映射。

不能默认画回归线或随意造气泡半径。无真实样本不能伪造真实分布；数据处理不改源数据。

## 6. 柱状图与热力图

附件bar是10类缺陷计数的柱状图：柱宽上限60、填充0.85、圆角3，仅应用通用轴布局，未实现专用小尺寸聚合。附件虽有Pareto命名，不含累计比例曲线，不宣称完整帕累托分析。

热力图未在附件实现，但保留此前业务方法：小尺寸依据连续数值网格和色阶分界绘制等高线，保留色块、色标与单位；不能用单元格描边或网格冒充等高线。只有截图不能反推真实网格。用户要求时补充该分支，不把它强加为默认附件五标签之一；可新增标签但标为扩展。

## 7. 颜色与适用范围

全图分类身份采用[所选领域规范](../../chart-spec/index.md)的适用色板。附件蓝绿橙红为示例配色，不覆盖当前领域色板；只有用户明确要求逐色忠实复现才保留。热力连续量仍用适用色阶。规范未覆盖某图形时用本方法实现，不为遵守已有图表清单而换载体。
