# Method 03｜按问题选能力

| 用户输入 | 分支与方案方向 |
| --- | --- |
| 首页小卡显示当前Yield 92.4%与最近一周趋势 | 03-1/2/3；关键值+Mini趋势+时间范围，不自动加截图窗口 |
| 电站小卡看告警状态、占比和最近一小时变化 | 03-1/3；用已有状态与占比数据，保留时间/分母，必要时组合轻量化 |
| 列表有30个对象，每行需要看当前值与近期走势 | 多对象维度+03-1/2/3；行内图、可比尺度与详情入口，不编综合排名 |
| 一页PPT放八个箱形图，点重叠 | 03-4/5；依据每张图可见箱体数选规则，不把八张图当N=8；只要静态输出时不强制窗口工具 |
| 按原Method 11演示右键截图、拖小与原貌 | 03-4/5原截图分支；完整参考阅读见[截图案例](snapshot-examples.md) |
| 只要散点透明度、点大小与恢复样式 | 03-5；轻量参数控件，恢复样式不改数据/窗口，不默认加所有截图交互 |
| 8个模型4指标，空间小但需比较优势短板 | 主05+辅03；保留平行坐标，选择有限空间能力，不套箱形专用规则 |

按需读取所选分支；扩展建议不冒充来源事实。仅参考矩阵的能力名称不能推定附件已有实现。
