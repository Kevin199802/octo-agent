# 多对象快速浏览｜跨能力应用维度

用于多对象的快速扫描，可组合03-1/2/3；不另设主方法。

- 以表格内嵌图、列表趋势或卡片趋势承载对象；对象名称、主指标、时间窗口的位置一致，利用03-1/2/3组织内容。
- 跨对象比绝对数值时采用可比单位和尺度；各图自适应范围只能看各自形状，需要说明不可凭高度比较绝对水平。不因排序/筛选重分颜色或悄悄改变统计口径。
- 多对象的快速扫描不同于多对象×多指标综合比较；后者以05为主，03只辅助有限空间呈现，不替换其平行坐标首选。
- 详情带入选中对象和时间。联动为按需扩展，不把普通详情入口称为跨图联动。

根据真实任务选择表格、列表或卡片，不默认三种全做，不自行增加排名、告警阈值或综合评分。
