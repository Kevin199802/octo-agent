# Method 03｜有限空间表达模式｜验收与证据

先明确任务、分支及输出媒介，再检查实际范围。执行状态用“通过/失败/未执行/不适用”；如用户要求PASS/PARTIAL/FAIL，另给质量结论，未执行不得标PASS。

| 检查范围 | 通过条件 |
| --- | --- |
| 任务及子能力 | 按实际问题命中03及必要分支；不凭状态一词误路由，不把五类全套上 |
| 阅读成本 | 首页概览不读半导体HTML；截图参考读完整资产；500/430不泛化 |
| 03-1 | 主次信息清楚、状态有依据、详情能保留对象/时间；要求配置时实际生效 |
| 03-2 | 核心趋势、单位、时间可理解，精简不掩盖关键异常，不仅机械缩图 |
| 03-3 | 趋势与值对齐时间口径；关键点有据，告警占比有分母，无伪造阈值 |
| 03-4 | 保持统计语义与异常；N按可见箱体；缺样本不造密度；聚合不声称概率面积 |
| 03-5 | 响应与参数实际生效；原貌/恢复样式不混淆；要求图片时真实输出文件 |
| 多对象维度 | 对象身份稳定、可比尺度明确；不越界发明评分或替代05 |
| 实现与规范 | 区分参考资产已有能力与需新增的能力；遵从所选领域规范 |

截图参考分支按[专项验收](snapshot-evaluation.md)追加检查；它不是普通首页的必测清单。只做文字建议不声称拖动、渲染、导出通过。编译、视觉交互、导出和业务接入分别记录实际结果，不以静态链接通过替代。

Mini新增验收：平稳噪声、密集小波动、少量显著峰谷、不同采样密度及宽度。检查显著峰谷保留、细小噪声不密集标记、近竖直方向修正、标记无重叠；比较卡片尺度可解释，详情携带正确上下文。不以未确认固定阈值作为通过条件。
