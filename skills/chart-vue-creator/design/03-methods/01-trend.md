# Method 01｜趋势变化难观察

## 问题与任务

周期长、点数多或震荡明显时，用户难以同时看清整体走势、原始波动和局部异常。先区分趋势比较、稳定性观察和异常定位。

## 设计能力

按任务组合：曲线平滑滑杆、原始/平滑叠加、框选放大、时间范围调整、局部缩放、异常阶段高亮、多曲线聚焦。无需每次提供全部能力；可按任务推荐载体。

## 关键边界

- 数据平滑后原始信息保留或可恢复；不默默替代稳定性、尖峰和异常信息。
- 区分连线几何平滑与数据序列平滑；不因组件名 Smooth 推断它已实现降噪。
- 当前不要求用户提供或确认算法才能生成原型。需要数据平滑时，可选择适合任务的可解释算法和可调参数，标为本次实现并简要说明。
- 不声称复现未提供的历史 HTML 算法或内部组件能力；不把一次参数推广为通用规范。
- 业务异常阈值来自业务；未知时可由用户框选关注阶段，不称为系统判定异常。
