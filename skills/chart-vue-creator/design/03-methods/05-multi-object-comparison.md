# Method 05｜多对象、多指标综合比较困难

## 问题与任务

多个对象×多个指标，识别差异、各指标内相对优势/短板和表现轮廓。先区分视觉比较与明确要求的综合评分。

## Preferred Carrier

**平行坐标图（Parallel Coordinates）**。

来源状态沿用原包：来自开发者领域交流中发现并验证的设计做法，已进入最新“领域图表设计共性问题矩阵”的“可沉淀设计能力”。配套能力：对比高亮、排序比较、指标方向统一、必要时对象筛选/Focus。

## 适配判断

- 观察多对象在多指标上的相对位置：优先平行坐标，保留各轴原值和单位。
- 仅单指标排名：直接排序；主要看变量或指标关系：读取已编写的04；只精确读值并逐列排序：表格可为主。
- 用户指定其他图表时可分析并实现，不回写默认知识；不因“均衡”主动推荐雷达图。
- 载体因媒介、实际密度或任务不适配时，可说明理由调整；不能只因缺专项规范换图。

## 关键边界

- 无业务评价模型时不默认等权、不求和评分、不用面积排名；陈述各指标内相对于当前群体的位置。
- 原始轴到像素的映射可正常计算；不把中间值包装成统一业务分数。
- 越高/越低越好可用轴方向与标签；目标值/区间型加目标标记，不强行统一为向上更好。
- 默认 Focus、Pin、高亮和对象筛选保持会话中的轴范围、顺序与对象色；需要重算时显式切换并标记参照群体变化。
- 视觉均衡仅描述指定参照范围下的轮廓；无共同业务基准时不等同于综合最优。
