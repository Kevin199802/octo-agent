1. 有明确旧版本/“旧版”限定，按该历史含义处理；不要全局替换字符串数字。
2. 无旧版本限定，裸编号采用当前表：11构成、12复用、13跨模块传递。
3. 用户明确说半导体截图、浮动快照、原貌对照但编号写11，解释一句“该截图任务现归03”并按任务继续；不让编号冲突阻止清晰任务。
4. 编号与名称冲突且任务不清楚时再澄清，不默认都当旧截图。历史测试/CHANGELOG原文不参与当前路由。
