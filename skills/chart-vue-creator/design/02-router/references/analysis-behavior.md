# 分析行为识别

| 行为 | 用户要判断什么 | 方法 |
| --- | --- | --- |
| Monitoring | 有限空间看当前值/状态；或从大量对象筛异常 | 分别03 / 02 |
| Trend | 单指标走势与异常阶段 | 01 |
| Correlation | 指标同步、变量关系 | 04-1 / 04-2；相关不等于因果 |
| Comparison | 独立对象的多指标优势短板 | 05；单指标可直接排序 |
| Diagnosis | 结合多个视角定位异常原因 | 04-3 |
| Event Reconstruction | 依据事件记录回顾发生、演变和恢复 | 06；缺记录不制造事件 |

行为辅助方法选择，不能替代短卡的适用条件；方法状态见[索引](../../03-methods/index.md)。
