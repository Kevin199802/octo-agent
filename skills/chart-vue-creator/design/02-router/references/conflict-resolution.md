# 路由冲突判断

以分析目标决定方法，再用对象类型和数据证据核对。数据列数、指标数或多个取值本身不能证明是综合比较。

| 比较边界 | 选择依据 | 示例 |
| --- | --- | --- |
| 04与05 | 问参数和结果的关联用04；问独立对象优势短板用05 | Batch Size与Accuracy/Loss关系→04-2；模型TTFT/成本/吞吐比较→05 |
| 02与03 | 发现异常对象用02；有限空间内呈现当前值、状态和走势用03 | 列出异常设备→02；小卡展示温度与近期走势→03 |
| 03与04 | 关注“现在怎样”且有表达限制用03；探索关系或原因用04 | 状态小卡→03；多视图追查Yield异常→04-3 |
| 04与06 | 找关联原因用04-3；根据事件记录还原过程用06 | 分析功率与电压关系→04；回顾告警到恢复→06 |

一个主方法可结合必要辅助方法；有事件先后记录不等于有因果证据。02当前状态与回退见[方法索引](../../03-methods/index.md)和[路由表](../route-map.md)。
