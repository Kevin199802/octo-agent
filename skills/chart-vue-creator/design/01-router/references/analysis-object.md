# 分析对象识别

对象类型辅助理解任务，必须与用户要完成的判断结合；同一种数据可服务不同任务。

| 对象 | 示例 | 按目标选择方法 |
| --- | --- | --- |
| Object：独立实体 | 模型、产品、版本、方案 | 多指标优劣比较05；单指标最高/最低可直接排序 |
| Variable：输入变量 | Batch Size、学习率、配置参数 | 参数与结果关系04-2；时间过程另判断是否04-1 |
| State：当前状态 | CPU、温度、功率 | 有限空间概览03；大量对象异常筛选02；单序列走势01 |
| Event：事件记录 | 故障、告警、构网事件 | 过程回顾06；关联诊断04-3；无记录时不推断事实事件 |

与[分析行为](analysis-behavior.md)结合消歧，不把类别名称当强制路由。
