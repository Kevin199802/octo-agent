## 解析顺序

1. 有明确版本或矩阵来源时按表映射；不能全局替换数字。裸01～10采用当前含义，裸10为流程衔接与复用。
2. 裸11～13不是当前方法ID。有明确任务时按任务继续并简述对应编号；只有编号且来源不明时询问任务或来源，不能将所有旧11默认当截图或构成。
3. 明确半导体截图、浮动快照、原貌对照但写11时，说明现归03并继续。只有“旧版11”且无其他上下文时，区分截图与0916-C构成。
4. 编号与名称冲突但任务清楚时按任务处理；任务仍有歧义才澄清。历史测试结果与CHANGELOG不参与当前路由。
