## 二、运营版 Release Notes(对外宣传口径)

> 以下为面向内网用户的推广文案,可直接复制使用。

**Octo Insight 0.7.0 更新亮点**

### 新功能

**产物一键归档到用研平台**
分析产出的文档与原型可以直接归档上传至用研平台。上传在后台进行,不打断当前对话;新增任务中心,可随时查看上传进度、暂停或取消,完成后一键复制访问链接。

**输入框「@」快速引用**
输入 `@` 即可唤起面板,快速引用技能或用研资产,选中后以标签形式嵌入,不用再手打文件名或路径。

**question 工具**
技能执行中需要你补充信息时,会通过 question 工具在对话里给出选项,直接点选即可继续,不必手打回复。

**排队消息自动继续**
等待回复期间排队的消息,现在切到其他页面或标签也不受影响,当前回答结束后会自动接着发送。

### 优化与修复

- **优化产物落盘**:产物卡片新增「准备中 / 失败可重试」状态提示;文件名保留原样,不再出现括号、空格被替换;修复同一产物重复出现、点击已删除文件无响应的问题。
- **优化文件管理**:修复输入框附件有时进不了文件管理;生成文件补齐「添加至会话区」与删除操作;Office 文档下载改走本地拷贝,速度更快。
- **优化权限确认弹窗**:视觉改版,点击文件路径可直接定位到本机文件。
- **安全性修复**:修复 Windows 下跨盘符可能绕过目录授权的问题。
