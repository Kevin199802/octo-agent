## 二、运营版 Release Notes(对外宣传口径)

> 以下为面向内网用户的推广文案,可直接复制使用。

**Octo Insight 0.6.0 更新亮点**

**全新「文件管理」面板**
会话中的文件现在有了统一的管理入口:支持文件夹层级浏览与面包屑导航、文件预览、多选批量操作,可上传文件或整个文件夹,并支持下载、删除以及一键添加至当前会话。上传重名文件将自动以「(1)」「(2)」后缀区分,与操作系统习惯一致。

**会话文件相互隔离**
每个会话的本地文件独立存放、互不干扰,切换会话不再看到其他会话的文件,管理与查找更清晰。

**研究工具显式入口**
输入框新增「研究工具」快捷选项:需要调用某个研究工具时直接点选即可,该轮对话将严格按所选工具执行,调用行为更可控、结果更可预期。各工具均配有说明提示,便于快速上手。

**Office 文档本地解析**
新增文档本地解析能力:Word、Excel、PowerPoint、PDF 文件可直接在本机提取正文供分析使用,无需经过上传链路,响应更快,数据不出本机。

**连接稳定性提升**
优化了外部研究服务的连接检查与断线重连机制:启动时仅检查当前所需的服务,降低等待时间;网络波动后的自动重连更可靠。

**体验细节优化**
优化对话内分隔线间距;文档产物卡片新增「打开所在文件夹」按钮;修复了附件文件名不一致导致工具读取失败等问题。
