## 二、运营版 Release Notes(对外宣传口径)

**Octo Insight 0.6.18 更新亮点**

**窗口自适应**
窗口缩小时,文件管理面板与侧边栏会依次自动收起,小屏笔记本也能正常使用;面板可随时手动展开。

**文件管理更好用**
新增文件预览(支持图片),双击直接在标签页打开;对话中上传的文件自动出现在列表中,无需手动刷新;不支持添加至会话的格式会明确提示原因。

**产物自动归位**
分析生成的文档、思维导图等产物会自动保存到当前会话的输出目录并出现在文件管理中,不再需要手动下载;修复了同一产物重复出现、点击卡片打不开文件等问题。

**思维导图导出白板格式**
思维导图可导出为 Octo 白板格式,直接在白板中继续编辑。

**下载与打包修复**
修复了内网环境下产物下载失败、多选打包后文件名乱码与 Windows 打不开压缩包的问题。
